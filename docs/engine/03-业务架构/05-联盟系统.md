# 业务架构 · 联盟系统 

> 管理玩家之间的组织关系——创建、加入、退出、权限、联盟间外交状态，SLG社交与战略的核心载体。

---

## 核心模块定义

**是什么**：管理玩家之间的组织关系——创建、加入、退出、权限、联盟间外交状态。

**为什么是核心模块**：每个SLG都有联盟（或公会、阵营、国家）。联盟是SLG社交和战略的核心载体。框架提供联盟的状态机和权限管理，具体权限列表和外交状态由内容配置定义。

**配置注入方式**：

| 扩展点 | 用途 | 契约摘要 |
|-----------|------|---------|
| alliance_ranks | 联盟等级/职位 | 职位ID→{权限列表, 人数上限}映射 |
| alliance_permissions | 权限定义 | 权限ID→{描述, 默认持有者}映射 |
| alliance_diplomacy_states | 外交状态 | 状态ID→{名称, 效果列表, 转换条件}映射 |
| alliance_creation_rules | 创建规则 | 规则列表，定义创建联盟的条件 |
| alliance_join_rules | 加入规则 | 规则列表，定义加入联盟的条件 |
| alliance_quit_rules | 退出规则 | 规则列表，定义退出联盟的条件和惩罚 |
| alliance_benefits | 联盟福利 | 福利ID→{条件, 效果}映射 |
| alliance_upgrade_rules | 升级规则 | 规则列表，定义联盟升级的条件和效果 |

## 框架默认行为

- 默认职位：盟主、副盟主、成员
- 默认权限：盟主全权，副盟主部分权，成员基本权
- 默认外交状态：中立、同盟、敌对
- 默认创建条件：无
- 默认退出惩罚：无
- 联盟状态变更触发 `alliance.state_changed` 事件
- 外交状态变更触发 `alliance.diplomacy_changed` 事件

## 约束

- 一个玩家同一时刻只能属于一个联盟
- 盟主不可直接退出（必须先转让）
- 外交状态变更必须双方确认（宣战除外）
- 联盟解散时所有成员自动退出

### 边界条件

| 参数 | 默认值 | 可配 | 说明 |
|------|--------|------|------|
| max_alliance_members | 100 | 是 | 单联盟最大成员数 |
| max_alliances_per_server | 200 | 是 | 单服联盟总数上限 |
| max_alliance_level | 10 | 是 | 联盟等级上限 |
| diplomacy_transition_cooldown_seconds | 3600 | 是 | 外交状态转换冷却时间 |
| max_alliance_benefits | 20 | 是 | 单联盟福利数量上限 |
| alliance_operation_timeout_seconds | 5 | 是 | 联盟操作超时（创建/解散/踢人等） |
| max_invitations_pending | 50 | 是 | 单联盟待处理邀请数上限 |

## 与其他核心模块的关系

- **依赖**：
  - 实体系统（L0层）——联盟成员是玩家实体；联盟本身也可视为一种特殊实体。
  - 规则系统（L3层）——联盟福利、升级条件、外交转换条件通过规则系统配置和触发。
- **被依赖**：
  - 赛季系统（L3层）——赛季重置可能重置联盟领土但保留联盟关系；赛季积分可按联盟统计。
- **层级定位**：L3层业务核心模块，建立在实体与规则之上，是社交战略层。
