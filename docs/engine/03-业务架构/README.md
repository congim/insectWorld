# 业务架构

> SLG品类特有的业务机制。这些核心模块是"SLG这个游戏类型需要的"，换成RPG/MOBA就不需要了。

## 包含的核心模块

| # | 核心模块 | 职责 | 依赖 |
|---|------|------|------|
| 1 | [地图系统](01-地图系统.md) | SLG空间模型：网格、地形、领土 | 实体 |
| 2 | [移动系统](02-移动系统.md) | 军队行军、路径规划、拦截 | 地图、实体 |
| 3 | [战斗系统](03-战斗系统.md) | 冲突解决：伤害计算、战斗流程、战报 | 移动、实体、Buff |
| 4 | [经济系统](04-经济系统.md) | 资源流转：产出、采集、贸易、掠夺 | 实体、Buff |
| 5 | [联盟系统](05-联盟系统.md) | 玩家组织：外交、战争、科技 | 实体、规则 |
| 6 | [赛季系统](06-赛季系统.md) | 周期运营：阶段、重置、遗产 | 规则、经济 |
| 7 | [事件系统](07-事件系统.md) | 游戏事件：天气、天灾、随机事件 | 规则、Buff |

## 与技术架构的关系

业务架构核心模块依赖技术架构核心模块：
- 所有业务核心模块都依赖**实体系统**（创建/管理游戏对象）
- 大部分业务核心模块依赖**Buff系统**（属性加成/减益）
- 大部分业务核心模块依赖**规则系统**（触发-动作逻辑）
- 所有业务核心模块通过**事件总线**通信
- 所有业务核心模块的状态通过**网络同步**和**持久化**处理

## SLG业务特征

这些核心模块体现了SLG的核心业务特征：
- **空间争夺**：地图+移动+战斗 → 领土占领
- **经济发展**：经济+采集+贸易 → 资源积累
- **社交对抗**：联盟+外交+战争 → 群体博弈
- **长线运营**：赛季+遗产+排行 → 周期循环
- **动态世界**：事件+天气+天灾 → 环境变化
