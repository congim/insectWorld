# 同步契约

> 定义服务端向客户端同步数据的分类、策略和频率，以及客户端预测的规则和修正机制。

---

## 同步分类

| 分类 | 说明 | 触发时机 | 数据量 | 适用场景 |
|------|------|---------|--------|---------|
| 全量快照 | 发送完整状态 | 首次连接/断线重连 | 大 | 初始化、恢复 |
| 增量同步 | 只发送变化的字段 | 每tick/变更时 | 小 | 运行时常规更新 |
| 事件推送 | 关键事件即时通知 | 事件发生时 | 极小 | 战斗开始/结束、赛季切换 |
| 视野同步 | 只同步玩家可见范围的数据 | 视野变化时 | 中 | 地图、实体位置 |
| 不同步 | 纯服务端内部状态 | 不同步 | 无 | 事件队列、规则冷却、内部计时器 |

## 预测规则

### 预测分类

| 操作类型 | 可否预测 | 预测内容 | 原因 |
|---------|---------|---------|------|
| 移动请求 | 是 | 预览路径+消耗+到达时间 | 路径计算可本地复现，服务端可能因阻挡等因素修正 |
| 资源采集 | 是（乐观） | 本地先扣减采集者时间，显示采集进度 | 低风险，服务端确认或回滚 |
| 聊天发送 | 是（乐观） | 立即显示消息 | 纯展示，服务端仅做敏感词过滤 |
| UI操作 | 是 | 选中/展开/切换 | 纯本地，不涉及游戏状态 |
| 战斗请求 | 否 | - | 战斗结果必须服务端裁决，预测会导致显示虚假结果 |
| 建筑升级 | 否 | - | 涉及资源消耗，必须服务端确认 |
| 招募兵种 | 否 | - | 涉及资源消耗和队列管理 |
| 联盟操作 | 否 | - | 涉及多人状态，必须服务端确认 |
| 科技研究 | 否 | - | 涉及资源消耗和前置条件校验 |
| 外交操作 | 否 | - | 涉及多联盟状态，必须双方确认 |
| 交易操作 | 否 | - | 涉及资源转移，必须服务端裁决 |
| 传送 | 否 | - | 涉及消耗和冷却，必须服务端确认 |

### 预测修正流程

```
客户端发送请求
  │
  ├─ 记录请求ID + 预测状态 + 时间戳
  │
  ├─ 如果可预测：
  │    ├─ 本地执行预测（如显示预览路径）
  │    ├─ 标记为"预测中"
  │    └─ 等待服务端响应
  │
  ├─ 如果不可预测：
  │    ├─ 显示"处理中"指示
  │    └─ 等待服务端响应
  │
  ▼
服务端响应到达
  │
  ├─ 成功 + 预测一致 → 确认预测，移除"预测中"标记
  │
  ├─ 成功 + 预测不一致 → 回滚预测，应用服务端结果
  │    └─ 示例：客户端预览路径A，服务端返回路径B（因新增阻挡）
  │       → 清除路径A显示，按路径B渲染
  │
  ├─ 失败 → 回滚预测，显示错误信息
  │    └─ 示例：资源不足 → 恢复本地资源显示，提示"资源不足"
  │
  └─ 超时（默认5秒） → 回滚预测，显示"网络延迟"提示
       └─ 超时不代表请求失败，服务端可能仍在处理
          → 后续响应到达时仍需处理
```

### 预测安全约束

| 约束 | 说明 |
|------|------|
| 预测不修改权威数据 | 预测只修改本地缓存中标记为"预测中"的字段，不覆盖已确认数据 |
| 预测可回滚 | 每个预测必须记录原始状态，以便回滚 |
| 预测有超时 | 超过5秒未收到响应的预测自动回滚 |
| 预测不级联 | 一个预测不触发另一个预测（避免预测链） |
| 预测限速 | 同一实体的预测操作间隔不小于100ms |

## 同步优化策略

### 带宽优化

| 策略 | 说明 | 配置项 |
|------|------|--------|
| 视野裁剪 | 不同步玩家视野外的实体状态 | sync.sync_scope_rules → vision |
| 增量压缩 | 只同步变化的字段，使用delta编码 | sync.sync_priority_rules → delta |
| 量化压缩 | 位置坐标量化到0.1精度 | sync.sync_priority_rules → quantize |
| 优先级排序 | 关键数据先同步，非关键数据延后 | sync.sync_priority_rules → priority |
| 批量发送 | 多个小增量合并为一个消息 | 每tick批量打包 |

### 一致性保障

| 机制 | 说明 |
|------|------|
| 序列号 | 每个同步消息带序号，客户端检测丢包并请求补发 |
| 心跳检测 | 每15秒心跳，超时60秒判定离线 |
| 快照校验 | 重连后全量快照带校验和，客户端校验数据完整性 |
| 冲突解决 | 服务端结果永远覆盖客户端预测，无例外 |
