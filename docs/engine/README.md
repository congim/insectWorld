## 能力模型

不再以固定“多少根骨头”描述平台，因为模块会随真实用例演进。统一使用三类：

### 通用技术能力

配置版本、事件契约、公式求值、规则动作注册、持久化适配、网络同步、可观测性和安全等。它们不得包含 SLG 或昆虫题材知识。

### 可选 SLG 领域模块

地图、移动、战斗、经济、联盟、赛季等。模块可组合、可关闭，不要求每个游戏或部署都启用全部能力。

### 游戏包与扩展

游戏包提供内容、数值和装配；配置不能安全表达的专属行为通过公开扩展接口实现。领域模块不得反向依赖游戏包。

## 通用性声明

“存在扩展点”不等于“配置可以表达完整玩法”。能力只有同时满足以下条件才可称为通用：

- 至少两个真实用例共享同一实现；
- 契约测试覆盖正常、失败和版本兼容路径；
- 引擎代码没有题材字符串和数值；
- 第二个用例不需要修改通用内核。

三国和星际材料目前只用于反例与契约测试，不是并行开发的游戏产品。
