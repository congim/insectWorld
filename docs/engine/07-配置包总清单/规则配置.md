# 规则配置

本部分包含规则相关的配置文件 Schema 定义：rules.json、events.json、buffs.json、formulas.json、counter_matrix.json。

---

## rules.json — 规则定义

```json
{
  "rule_definitions": [],
  "rule_groups": [],
  "rule_conditions": [],
  "rule_actions": [],
  "rule_priority_policy": { "ordering": "higher_first", "tie_breaking": "registration_order" },
  "rule_cooldown_rules": []
}
```

**扩展点**：rule.rule_definitions, rule.rule_groups, rule.rule_conditions, rule.rule_actions

**依赖**：所有其他配置

---

## events.json — 事件定义

```json
{
  "event_types": [],
  "event_filters": [],
  "event_transformers": [],
  "event_priority_rules": [],
  "event_history_rules": []
}
```

**扩展点**：event.event_types, event.event_filters, event.event_transformers

**依赖**：rules.json

---

## buffs.json — Buff定义

```json
{
  "buff_types": [],
  "buff_effects": [],
  "buff_stacking_rules": [],
  "buff_trigger_rules": [],
  "buff_aura_rules": [],
  "buff_dispel_rules": []
}
```

**扩展点**：buff.buff_types, buff.buff_effects, buff.buff_stacking_rules

**依赖**：entity.entity_attributes

---

## formulas.json — 公式定义

```json
{
  "formulas": [
    {
      "formula_id": "basic_damage",
      "name": "基础伤害",
      "expression": "attacker.atk * counter_multiplier - defender.def",
      "variables": [
        { "var_name": "attacker.atk", "source": "attacker_attribute", "default_value": 0 },
        { "var_name": "counter_multiplier", "source": "counter_matrix", "default_value": 1.0 },
        { "var_name": "defender.def", "source": "defender_attribute", "default_value": 0 }
      ]
    }
  ]
}
```

**扩展点**：combat.damage_formulas, economy.production_rules, economy.consumption_rules

**依赖**：resources.json, units.json

---

## counter_matrix.json — 克制关系矩阵

```json
{
  "counter_matrix": {
    "worker": { "worker": 1.0, "soldier": 0.5, "tank": 0.3 },
    "soldier": { "worker": 2.0, "soldier": 1.0, "tank": 0.6 },
    "tank": { "worker": 3.0, "soldier": 1.5, "tank": 1.0 }
  }
}
```

**扩展点**：combat.counter_matrix

**依赖**：units.json
