# 实体配置

本部分包含实体相关的配置文件 Schema 定义：factions.json、units.json、buildings.json、heroes.json、techs.json。

---

## factions.json — 种族/阵营定义

```json
{
  "factions": [
    {
      "faction_id": "red_ant",
      "name": "红蚁族",
      "description": "好战的红色蚂蚁",
      "faction_modifiers": {
        "atk": 1.1,
        "def": 0.9
      },
      "exclusive_units": ["ant_warrior"],
      "exclusive_buildings": ["war_nest"]
    }
  ]
}
```

**扩展点**：entity.entity_types, entity.entity_tags

**依赖**：game.json

---

## units.json — 兵种/单位定义

```json
{
  "units": [
    {
      "type_id": "ant_worker",
      "name": "工蚁",
      "category": "unit",
      "faction": "red_ant",
      "unit_type": "worker",
      "base_attributes": { "hp": 50, "atk": 5, "def": 3, "speed": 2 },
      "default_components": ["movable", "attackable", "harvestable"],
      "default_tags": ["insect", "worker", "ground"],
      "cost": { "food": 50 },
      "training_time_seconds": 30
    }
  ]
}
```

**扩展点**：entity.entity_types, entity.entity_attributes, entity.entity_tags

**依赖**：factions.json, entity.entity_components

---

## buildings.json — 建筑定义

```json
{
  "buildings": [
    {
      "type_id": "ant_hill",
      "name": "蚁丘",
      "category": "building",
      "faction": "red_ant",
      "base_attributes": { "hp": 500, "def": 20 },
      "default_components": ["producible", "upgradeable"],
      "default_tags": ["building", "nest"],
      "build_cost": { "food": 200, "dirt": 100 },
      "build_time_seconds": 120,
      "max_level": 10,
      "upgrade_cost_formula": "base_cost * level * 1.5"
    }
  ]
}
```

**扩展点**：entity.entity_types, entity.entity_attributes

**依赖**：factions.json

---

## heroes.json — 英雄定义

```json
{
  "heroes": [
    {
      "type_id": "ant_general",
      "name": "蚁将",
      "category": "hero",
      "faction": "red_ant",
      "base_attributes": { "hp": 200, "atk": 30, "def": 15, "speed": 3, "command": 5 },
      "skills": ["rally", "war_cry"],
      "growth_curve": "linear",
      "max_level": 50
    }
  ]
}
```

**扩展点**：entity.entity_types, entity.entity_attributes, combat.combat_skills

**依赖**：factions.json

---

## techs.json — 科技定义

```json
{
  "techs": [
    {
      "tech_id": "reinforced_carapace",
      "name": "强化甲壳",
      "description": "提升所有蚂蚁的防御力",
      "prerequisites": [],
      "research_cost": { "food": 500 },
      "research_time_seconds": 3600,
      "effects": [
        { "effect_type": "apply_buff", "parameters": { "buff_id": "carapace_bonus", "target_tag": "insect" } }
      ]
    }
  ]
}
```

**扩展点**：rule.rule_definitions, buff.buff_types

**依赖**：units.json, buildings.json
