# 运营配置

本部分包含运营相关的配置文件 Schema 定义：season.json、alliance.json、resources.json、terrains.json、movement.json、combat.json、economy.json。

---

## season.json — 赛季定义

```json
{
  "season_phases": [],
  "season_transition_rules": [],
  "season_reset_rules": [],
  "season_inherit_rules": [],
  "season_rewards": [],
  "season_events": [],
  "season_scoring_rules": []
}
```

**扩展点**：season.season_phases, season.season_transition_rules, season.season_reset_rules, season.season_inherit_rules, season.season_rewards, season.season_scoring_rules

**依赖**：rules.json, resources.json

---

## resources.json — 资源类型定义

```json
{
  "resources": [
    {
      "type_id": "food",
      "name": "食物",
      "category": "primary",
      "max_amount": 100000,
      "display_priority": 1,
      "tradeable": true
    }
  ]
}
```

**扩展点**：economy.resource_types

**依赖**：无

---
