# 全局配置 (game.json)

## game.json — 游戏全局配置

游戏全局配置文件，定义游戏的基础参数，包括名称、版本、格子类型、地图尺寸等。

### Schema 定义

```json
{
  "game_name": "游戏名称",
  "game_version": "1.0.0",
  "framework_version": "3.0",
  "grid_type": "hex",
  "map_dimensions": { "width": 200, "height": 200 },
  "tick_rate": 10,
  "language": "zh-CN"
}
```

### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `game_name` | string | 是 | 游戏名称 |
| `game_version` | string | 是 | 游戏版本号（语义化版本） |
| `framework_version` | string | 是 | 框架版本号 |
| `grid_type` | string | 是 | 格子类型：`hex`（六角格）/ `square`（四角格）/ `free`（自由坐标） |
| `map_dimensions` | object | 是 | 地图尺寸，包含 `width` 和 `height` |
| `tick_rate` | number | 是 | 逻辑tick频率（次/秒） |
| `language` | string | 否 | 默认语言（如 `zh-CN`、`en-US`） |

### 扩展点

- `map.map_grid_type`：格子类型扩展点
- `map.map_dimensions`：地图尺寸扩展点

### 依赖

无依赖，是所有其他配置文件的基础。
