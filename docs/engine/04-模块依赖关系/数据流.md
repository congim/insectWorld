# 核心数据流

> 以下5条数据流展示了框架在典型SLG场景中各核心模块如何协作。

---

## 数据流1：移动→战斗

```
玩家发起移动请求
  │
  ├─→ 移动系统：检查移动力、路径搜索
  │      movement.movement_types：获取移动类型
  │      movement.movement_costs：计算地形消耗
  │      movement.movement_blocking_rules：检查阻挡
  │
  ├─→ 移动系统：执行移动
  │     发布事件：movement.arrived
  │
  ├─→ 事件系统：分发movement.arrived事件
  │
  ├─→ 规则系统：检查是否触发战斗
  │      rule.rule_definitions：检查"到达敌方位置"规则
  │
  └─→ 战斗系统：开始战斗
         combat.combat_types：确定战斗类型
         combat.combat_phases：执行战斗阶段
         combat.damage_formulas：计算伤害
         combat.counter_matrix：应用克制
         combat.combat_skills：释放技能
        发布事件：combat.ended
```

## 数据流2：经济循环

```
经济系统：生产周期触发
  │
  ├─→  economy.production_rules：计算产出
  │     引用 Buff系统：生产加成
  │        buff.buff_types：查找生产加成Buff
  │        buff.buff_effects：计算加成值
  │
  ├─→ 经济系统：资源入库
  │      economy.storage_rules：检查仓储上限
  │     发布事件：economy.resource_changed
  │
  ├─→ 经济系统：消耗周期触发
  │      economy.consumption_rules：计算消耗
  │      economy.economy_modifiers：应用修正
  │
  └─→ 规则系统：检查资源相关规则
         rule.rule_definitions：如"资源不足触发惩罚"规则
        发布事件：rule.executed
```

## 数据流3：赛季循环

```
赛季系统：阶段转换触发
  │
  ├─→  season.season_transition_rules：检查转换条件
  │
  ├─→ 赛季系统：执行阶段转换
  │     发布事件：season.phase_changed
  │
  ├─→ 事件系统：分发phase_changed事件
  │
  ├─→ 规则系统：执行阶段效果规则
  │      rule.rule_definitions：阶段效果规则
  │      rule.rule_actions：阶段效果动作
  │
  ├─→ 赛季系统：赛季结束时
  │      season.season_reset_rules：执行重置
  │      season.season_inherit_rules：执行继承
  │      season.season_rewards：发放奖励
  │      season.season_scoring_rules：计算排名
  │     发布事件：season.ended
  │
  └─→ 持久化：赛季快照
         persistence.snapshot_rules：赛季快照规则
```

## 数据流4：联盟战争

```
联盟系统：外交状态变更
  │
  ├─→  alliance.alliance_diplomacy_states：状态转换
  │     发布事件：alliance.diplomacy_changed
  │
  ├─→ 事件系统：分发diplomacy_changed事件
  │
  ├─→ 规则系统：执行外交效果规则
  │      rule.rule_definitions：如"宣战后解除贸易"规则
  │
  ├─→ 经济系统：贸易变更
  │      economy.trade_rules：根据外交状态启用/禁用贸易
  │
  ├─→ Buff系统：联盟Buff变更
  │      buff.buff_types：同盟加成/敌对减益
  │
  └─→ 战斗系统：PvP开启/关闭
         combat.combat_types：根据外交状态启用/禁用战斗类型
```

## 数据流5：事件响应

```
事件系统：事件发布
  │
  ├─→  event.event_filters：过滤事件
  │
  ├─→  event.event_transformers：转换事件
  │
  ├─→ 规则系统：检查事件触发的规则
  │      rule.rule_definitions：匹配触发事件
  │      rule.rule_conditions：评估条件
  │      rule.rule_actions：执行动作
  │
  ├─→ Buff系统：检查事件触发的Buff
  │      buff.buff_trigger_rules：匹配触发事件
  │
  └─→ 赛季系统：检查事件触发的赛季逻辑
         season.season_events：匹配触发阶段
```
