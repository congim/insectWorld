# 模块依赖关系

> 核心模块不是孤立的，它们之间有明确的依赖和数据流。本文档描述核心模块之间的连接关系，是理解框架"如何运转"的关键。

---

## 核心模块依赖图

```
L5 ─────────────────────────────────────────────────────────
     │  网络同步    持久化                                │
     │  (依赖所有下层核心模块，提供跨层服务)                       │
L4 ─────────────────────────────────────────────────────────
     │  联盟系统  赛季系统  事件系统                    │
     │  (依赖L0-L3，提供高层逻辑)                             │
L3 ─────────────────────────────────────────────────────────
     │  战斗系统  规则系统                                │
     │  (依赖L0-L2，提供核心玩法逻辑)                         │
L2 ─────────────────────────────────────────────────────────
     │  移动系统  经济系统                                │
     │  (依赖L0-L1，提供动态行为)                             │
L1 ─────────────────────────────────────────────────────────
     │  地图系统  Buff系统                                │
     │  (依赖L0，提供空间和属性修改)                          │
L0 ─────────────────────────────────────────────────────────
     │  实体系统                                            │
     │  (基础层，无依赖)                                      │
     └────────────────────────────────────────────────────────
```

## 依赖规则

- 上层核心模块可以依赖同层或下层核心模块，不可依赖上层核心模块
- L0实体系统是唯一无依赖的核心模块，是所有其他核心模块的基础
- L5网络同步和持久化是横切关注点，依赖所有下层核心模块

## 各层详细依赖

| 层级 | 核心模块 | 直接依赖 |
|------|------|---------|
| L0 | 实体系统 | 无 |
| L1 | 地图系统 | 实体系统（实体放置在地图上） |
| L1 | Buff系统 | 实体系统（Buff挂载在实体上） |
| L2 | 移动系统 | 实体系统（移动实体）、地图系统（路径搜索） |
| L2 | 经济系统 | 实体系统（资源归属于实体）、Buff系统（经济加成） |
| L3 | 战斗系统 | 实体系统（战斗实体）、地图系统（地形效果）、移动系统（接战判定）、Buff系统（战斗Buff） |
| L3 | 规则系统 | 实体系统（规则作用于实体）、事件系统（规则由事件触发） |
| L4 | 联盟系统 | 实体系统（玩家实体）、规则系统（联盟规则）、经济系统（联盟福利） |
| L4 | 赛季系统 | 规则系统（赛季规则）、事件系统（赛季事件）、经济系统（赛季奖励） |
| L4 | 事件系统 | 实体系统（事件源和目标） |
| L5 | 网络同步 | 所有L0-L4核心模块（同步所有状态） |
| L5 | 持久化 | 所有L0-L4核心模块（持久化所有状态） |
