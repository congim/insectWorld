# 扩展接口（加扩展点）

## 6.3 扩展接口的场景和步骤

### 场景1：新增传送动作

**需求**：星际SLG需要"虫洞传送"——一种特殊的传送方式，有随机目的地

**分析**：现有 `movement.movement_teleport_rules` 支持传送，但目标约束不支持"随机目的地"

**步骤**：

1. 在移动系统中新增扩展点 `movement.movement_teleport_destination_generators`
2. 定义契约：`{ generator_id, name, generator_type, parameters }`
3. 在移动系统中实现目标生成器调用逻辑
4. 在 `movement_teleport_rules` 的 `target_constraint` 中新增 `generator` 字段
5. 更新文档，标注新增扩展点
6. 运行全量回归测试

**涉及的核心模块**：移动系统

**是否需要修改框架**：✅ 是（修改移动系统代码）

**风险**：🟡 中（只修改移动系统，不影响其他核心模块）

### 场景2：新增攻城准备阶段

**需求**：三国SLG的攻城战需要在战斗开始前有"攻城准备"阶段，玩家可以在准备阶段建造攻城器械

**分析**：现有 `combat.combat_phases` 支持自定义阶段，但阶段内的"可执行动作"需要框架支持"建造"动作类型

**步骤**：

1. 在战斗系统的 `combat_phases` 扩展点的 `executable_actions` 中新增 `build_siege_weapon` 动作类型
2. 在战斗系统中实现建造动作的处理逻辑（消耗资源→创建攻城器械实体→加入战斗）
3. 在 `combat.combat_phases` 中新增攻城准备阶段定义
4. 更新文档
5. 运行全量回归测试

**涉及的核心模块**：战斗系统、经济系统（建造消耗资源）

**是否需要修改框架**：✅ 是（修改战斗系统代码）

**风险**：🟡 中（战斗系统和经济系统交互，需要测试经济流转）

### 场景3：新增附庸外交状态

**需求**：三国SLG需要"附庸"外交状态，附庸需要向宗主进贡

**分析**：现有 `alliance.alliance_diplomacy_states` 支持自定义外交状态，但"进贡"效果需要经济系统的周期性资源转移支持

**步骤**：

1. 在 `alliance.alliance_diplomacy_states` 中新增附庸状态定义，effects中包含 `tribute` 效果
2. 在经济系统中新增扩展点 `economy.tribute_rules`，定义进贡规则
3. 定义契约：`{ rule_id, tribute_source, tribute_target, tribute_formula, interval_seconds }`
4. 在经济系统中实现进贡逻辑
5. 在联盟系统中将进贡效果与外交状态关联
6. 更新文档
7. 运行全量回归测试

**涉及的核心模块**：联盟系统、经济系统

**是否需要修改框架**：✅ 是（修改联盟系统和经济系统代码）

**风险**：🟡 中（两个核心模块的交互，需要测试进贡流程）
