# 框架能力边界

## 1.3 框架能力边界

### 管（框架负责）

| 领域 | 框架提供的能力 |
|------|---------------|
| 实体生命周期 | 创建、销毁、属性读写、组件挂载、实体查询 |
| 空间管理 | 六角格/四角格/自由坐标、地形映射、视野计算、区域划分 |
| 移动计算 | 路径搜索、移动力消耗、地形修正、编队移动、传送 |
| 战斗流程 | 回合/实时战斗流程编排、伤害计算管线、克制应用、战报生成 |
| 资源流转 | 生产、采集、交易、消耗、仓储上限、资源转换 |
| Buff系统 | 挂载、叠加、过期、触发、层数管理、来源追踪 |
| 规则引擎 | 条件-动作规则注册、优先级排序、规则互斥、规则链 |
| 事件总线 | 事件注册、订阅、派发、优先级、同步/异步派发 |
| 联盟状态机 | 创建、加入、退出、联盟间外交状态、权限管理 |
| 赛季循环 | 阶段定义、阶段转换、赛季重置、跨赛季数据继承 |
| 游戏事件 | 定时事件、随机事件、条件触发事件、事件脚本执行 |
| 网络同步 | 状态同步框架、增量同步、断线重连、房间管理 |
| 持久化 | 存档点定义、增量持久化、数据版本迁移、回滚 |
| 配置加载 | 配置文件加载、Schema校验、热更新、配置版本管理 |

### 不管（框架不负责）

| 领域 | 说明 | 归属 |
|------|------|------|
| 具体数值 | 攻击力、血量、速度等数值 | 配置 |
| 具体公式 | 伤害公式、经验公式等 | 配置 |
| 具体技能效果 | 火球术、冲锋等 | 配置 |
| 具体美术 | 模型、特效、UI美术 | 游戏产品层 |
| 具体UI布局 | 界面排版、交互流程 | 游戏产品层 |
| 具体世界观 | 背景故事、设定 | 游戏产品层 |
