# 错误处理与容错策略

## 1.6 错误处理与容错策略

### 错误分级

| 级别 | 定义 | 处理策略 | 示例 |
|------|------|---------|------|
| **FATAL** | 框架无法继续运行 | 记录日志 → 全量持久化 → 优雅停机 | 配置校验失败、DB连接断开且无法恢复 |
| **ERROR** | 某个功能不可用，但框架可继续 | 记录日志 → 跳过该功能 → 通知客户端 | 某个核心模块初始化失败、某个Command执行异常 |
| **WARN** | 非预期但可处理的情况 | 记录日志 → 继续运行 | 配置热更校验警告、资源溢出、Buff叠加超上限 |
| **INFO** | 正常但值得记录的事件 | 记录日志 | 玩家上线、赛季阶段切换、联盟创建 |

### 错误码规范

错误码格式：`<模块前缀>-<错误编号>`

| 模块前缀 | 核心模块 | 示例 |
|---------|---------|------|
| ENT | 实体系统 | ENT-001 实体不存在 |
| BUF | Buff系统 | BUF-003 叠加超上限 |
| RUL | 规则系统 | RUL-001 规则循环依赖 |
| EVT | 事件总线 | EVT-002 派发超时 |
| NET | 网络同步 | NET-005 断线 |
| SAV | 持久化 | SAV-001 写DB失败 |
| CFG | 配置加载 | CFG-004 校验失败 |
| MAP | 地图系统 | MAP-002 坐标越界 |
| MOV | 移动系统 | MOV-001 路径不可达 |
| CBT | 战斗系统 | CBT-003 计算异常 |
| ECO | 经济系统 | ECO-002 资源不足 |
| ALY | 联盟系统 | ALY-001 权限不足 |
| SSN | 赛季系统 | SSN-001 切换失败 |
| GME | 事件系统 | GME-002 脚本异常 |

- 错误编号001-099为框架保留，100+为配置扩展
- 每个错误码必须注册在错误码表中，含中英文描述和用户可见消息

### 容错原则

```
原则1：快速失败（Fail Fast）
  - 启动阶段：任何错误都快速失败，拒绝启动
  - 原因：带病运行比不运行更危险

原则2：优雅降级（Graceful Degradation）
  - 运行阶段：非核心功能失败时降级而非崩溃
  - 例：聊天系统挂了 → 游戏继续，聊天不可用
  - 例：排行榜挂了 → 游戏继续，排行不可用

原则3：可恢复（Recoverable）
  - 任何错误后，框架状态必须保持一致
  - 例：Command执行panic → recover → 记录日志 → 该Command丢弃 → 游戏继续
  - 例：tick超时 → 跳过非关键步骤 → 下tick恢复

原则4：可观测（Observable）
  - 任何错误都必须有日志和指标
  - 日志：结构化JSON，含时间/级别/核心模块/实体ID/堆栈
  - 指标：Prometheus格式，按核心模块和错误类型统计
```

### 各核心模块的错误处理

| 核心模块 | 错误场景 | 处理策略 |
|------|---------|---------|
| 实体系统 | 实体创建失败（内存不足） | ERROR → 拒绝创建 → 通知客户端 |
| 实体系统 | 实体ID冲突 | ERROR → 拒绝创建 → 记录日志 → 通知客户端 |
| 事件总线 | 事件处理panic | ERROR → recover → 记录日志 → 继续派发下一个 |
| 事件总线 | 事件订阅者响应超时 | WARN → 跳过该订阅者 → 记录日志 → 继续派发 |
| 配置加载 | 热更校验失败 | WARN → 保留旧配置 → 记录日志 |
| 配置加载 | 配置文件缺失 | FATAL → 拒绝启动（启动期）/ 保留旧配置（运行期） |
| 网络同步 | 消息序列化失败 | WARN → 丢弃消息 → 记录日志 |
| 网络同步 | 客户端断线 | INFO → 标记离线 → 启动重连宽限期 → 超时则清理 |
| 持久化 | 写DB失败 | ERROR → 重试3次 → 仍失败则FATAL |
| 持久化 | 存档数据版本不匹配 | ERROR → 触发迁移脚本 → 迁移失败则FATAL |
| 地图系统 | 坐标越界 | ERROR → 拒绝操作 → 通知客户端 |
| 地图系统 | 地形配置与地图尺寸不匹配 | FATAL → 拒绝启动 |
| 移动系统 | 路径不可达 | WARN → 返回失败 → 通知客户端 |
| 移动系统 | 移动力不足 | WARN → 中止移动 → 按已走距离结算 |
| 战斗系统 | 战斗计算异常 | ERROR → 强制结束战斗 → 按平局处理 |
| 战斗系统 | 参战实体中途销毁 | WARN → 移出战斗 → 按剩余实体继续 |
| 经济系统 | 资源计算溢出 | WARN → 钳制到上限 → 记录日志 |
| 经济系统 | 资源不足扣减 | ERROR → 拒绝扣减 → 通知客户端 |
| 联盟系统 | 联盟操作权限不足 | ERROR → 拒绝操作 → 通知客户端 |
| 联盟系统 | 联盟外交状态冲突 | WARN → 按优先规则裁决 → 记录日志 |
| 赛季系统 | 赛季切换失败 | FATAL → 全量持久化 → 停机（不能带病跑新赛季） |
| 赛季系统 | 赛季奖励发放失败 | ERROR → 记入补发队列 → 下tick重试 |
| 事件系统 | 事件脚本执行异常 | ERROR → 终止该事件 → 记录日志 → 游戏继续 |
| 事件系统 | 事件触发条件不满足 | INFO → 跳过 → 不记录（正常行为） |
