## 四、科技研究系统（统一）

### 4.1 研究限制（统一）

```
【同时研究限制】
  - 每个实验室同时只能研究1项科技
  - 实验室数量 = 城市等级（最多5个）

【科技解锁限制】
  - 科技有前置条件，必须研究前置科技后才能解锁
  - 科技树呈树状结构，不能跳跃研究
```

### 4.2 科技重置（统一）

```
【重置规则】
  - 可以重置已研究的科技
  - 重置后返还50%研究资源
  - 每天最多重置3次
```
