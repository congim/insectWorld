## 一、设计理念：标准化SLG框架

### 核心原则
```
所有种族共享同一套SLG底层逻辑，差异仅在于：
- 种族特性（被动技能，仅数值差异）
- 专属资源（获取方式不同，用途相同）
- 特殊建筑（外观+5%数值加成）
- 英雄技能（数值微调）

底层系统完全统一：
- 资源系统（4大公共资源+1专属资源）
- 建筑系统（标准槽位+标准功能）
- 兵种系统（标准属性+标准克制）
- 战斗系统（标准公式）
- 联盟系统（标准机制）
```

## 三、种族特性（仅数值差异）

### 3.1 蚁族 — 群体意识

```
【特性效果】
  周围5格友军共享视野
  集结速度+10%
  
【真实原型】
  蚂蚁通过信息素进行化学通讯，形成"集体智慧"
  
【游戏体现】
  视野共享：所有单位能看到周围5格内的敌人
  集结加成：军队集结时间减少10%
```

### 3.2 虫族 — 幻翅

```
【特性效果】
  飞行单位被攻击命中率-10%
  
【真实原型】
  蝴蝶的拟态和隐身能力
  
【游戏体现】
  飞行单位在攻击时，敌人命中率降低10%
```

### 3.3 甲虫族 — 铁甲

```
【特性效果】
  所有单位防御+10%
  
【真实原型】
  甲虫的几丁质外骨骼
  
【游戏体现】
  所有单位防御属性提升10%
```

### 3.4 蜂族 — 蜂群连接

```
【特性效果】
  周围5格友军攻击+10%
  
【真实原型】
  蜜蜂的信息素通讯和群体决策
  
【游戏体现】
  范围内友军攻击属性提升10%
```

### 3.5 螳螂族 — 瞬杀

```
【特性效果】
  首次攻击必定暴击（伤害+100%）
  
【真实原型】
  螳螂的伏击捕猎和快速攻击
  
【游戏体现】
  每场战斗第一次攻击必定暴击
```

### 3.6 蝗虫族 — 蝗潮

```
【特性效果】
  10秒内生产速度+10%
  
【真实原型】
  蝗虫的群居型和散居型转变
  
【游戏体现】
  激活后10秒内，所有兵营生产速度提升10%
```

### 3.7 蛆虫族 — 腐化

```
【特性效果】
  死亡地块每分钟产出1🦠腐质
  
【真实原型】
  苍蝇幼虫的腐食生活
  
【游戏体现】
  战斗死亡的地块会持续产出专属资源
```

## 四、英雄设计（标准化模板）

### 4.1 英雄属性标准

```
【英雄属性公式】
  血量 = 100 + 类型基础 × 5
  攻击 = 20 + 类型基础 × 2
  防御 = 10 + 类型基础 × 1
  速度 = 类型基础速度
  
【英雄等级】
  最高等级：50级
  每级提升：血量+5%，攻击+3%，防御+2%
```

## 五、种族差异化设计总结

| 维度 | 标准化内容 | 差异化内容 |
|------|------------|------------|
| 资源系统 | ✅ 4大公共+1专属 | 专属资源获取方式 |
| 建筑系统 | ✅ 标准槽位+功能 | 特殊建筑外观+5%加成 |
| 兵种系统 | ✅ 6类型+统一公式 | 数值微调（±10%） |
| 战斗系统 | ✅ 统一伤害公式 | 种族特性（被动） |
| 英雄系统 | ✅ 统一技能机制 | 技能数值差异 |
| 科技系统 | ✅ 统一科技树 | 专属科技数值差异 |
| 联盟系统 | ✅ 完全统一 | 无差异 |

## 六、设计优势

### 6.1 开发效率

```
【底层代码】
  - 资源系统：1套代码
  - 建筑系统：1套代码
  - 兵种系统：1套代码
  - 战斗系统：1套代码
  - 联盟系统：1套代码

【差异化配置】
  - 种族特性：7条配置
  - 专属资源：7条配置
  - 特殊建筑：7条配置
  - 英雄数据：14条配置
  - 兵种数值：49条配置
```

### 6.2 平衡性控制

```
【平衡重点】
  - 种族特性数值（±10%以内）
  - 兵种数值（±10%以内）
  - 英雄技能数值（±20%以内）

【平衡测试】
  - 同类型兵种数值对比
  - 种族特性胜率测试
  - 英雄技能强度测试
```

### 6.3 扩展性强

```
【新增种族】
  - 只需配置：特性+资源+建筑+英雄+兵种
  - 无需修改底层代码
  - 无需修改其他种族数据

【新增兵种】
  - 只需配置：成本+属性+类型
  - 自动继承种族特性和克制关系
```
