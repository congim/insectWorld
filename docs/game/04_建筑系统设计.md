|------|------|----------|------|

### 2.2 建筑升级（统一公式）

```
【升级时间】
  Lv.1→Lv.2：5分钟
  Lv.2→Lv.3：10分钟
  Lv.3→Lv.4：20分钟
  Lv.4→Lv.5：30分钟

【升级成本】
  成本 = 基础成本 × (1 + 等级 × 0.5)
  
  示例：
    采集营Lv.1→Lv.2：🌿200+🪨100
    采集营Lv.2→Lv.3：🌿400+🪨200
    采集营Lv.3→Lv.4：🌿600+🪨300
    采集营Lv.4→Lv.5：🌿800+🪨400
```

## 五、建筑位置系统（统一）

### 5.1 城市布局

```
【布局规则】
  - 城市中心固定在地图某一格
  - 建筑围绕城市中心建造（在控制地块上）
  - 城墙必须围绕城市中心
  - 建筑之间不能重叠
  - 建筑占用1格地块
```

### 5.2 地块占用示例

```
【Lv.1城市布局】
  城市中心：1格
  城墙：围绕城市中心的1格边框（8格）
  建筑槽位：6格
  
  总占用：15格
  控制半径：2格（5×5=25格）
  可用空地：10格
```

## 七、设计优势

### 7.1 开发效率

```
【底层代码】
  - 建筑系统：1套代码
  - 升级系统：1套代码
  - 位置系统：1套代码

【配置数据】
  - 公共建筑：7条配置
  - 特殊建筑：7条配置
  - 升级成本：35条配置
```

### 7.2 平衡性控制

```
【平衡重点】
  - 特殊建筑数值加成≤10%
  - 特殊建筑成本与普通建筑相当
  - 特殊建筑功能不改变核心玩法
```
