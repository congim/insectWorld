## 一、标准化英雄属性系统

### 1.1 英雄属性公式（统一）

```
【基础属性】
  血量 = 100 + 类型基础 × 5
  攻击 = 20 + 类型基础 × 2
  防御 = 10 + 类型基础 × 1
  速度 = 类型基础速度
  
【类型基础】
  城市核心：血量300 攻击30 防御20 速度慢
  军事指挥官：血量250 攻击50 防御30 速度中
  侦察统领：血量200 攻击20 防御10 速度快
  英雄单位：血量400 攻击40 防御25 速度中
```

### 1.2 英雄等级（统一）

| 等级 | 血量 | 攻击 | 防御 | 速度 |
|------|------|------|------|------|
| 1 | 100% | 100% | 100% | 100% |
| 10 | 120% | 120% | 110% | 105% |
| 20 | 150% | 150% | 130% | 110% |
| 30 | 190% | 190% | 160% | 115% |
| 40 | 240% | 240% | 200% | 120% |
| 50 | 300% | 300% | 250% | 125% |

## 二、标准化英雄技能系统

### 2.1 技能类型（统一4类）

| 类型 | 效果 | 冷却 | 代表 |
|------|------|------|------|
| 治疗型 | 恢复友军血量 | 90-120秒 | 蚁后·琥珀 |
| 增益型 | 提升友军属性 | 90秒 | 将军·铁颚 |
| 爆发型 | 对敌人造成巨额伤害 | 90秒 | 死神领主 |
| 召唤型 | 召唤单位参战 | 120秒 | 蜂后·金刺 |

### 2.2 技能数值标准（统一）

```
【治疗型技能】
  治疗量 = 英雄等级 × 10 + 50
  治疗范围 = 周围5-10格
  冷却时间 = 90-120秒

【增益型技能】
  属性加成 = 20-30%
  持续时间 = 15-20秒
  冷却时间 = 90秒

【爆发型技能】
  伤害倍数 = 150-200%
  目标数量 = 1-3个
  冷却时间 = 90秒

【召唤型技能】
  召唤数量 = 10-20个
  持续时间 = 永久/30秒
  冷却时间 = 120秒
```

## 五、标准化英雄死亡与重生

### 5.1 英雄死亡（统一）

```
【死亡机制】
  - 英雄血量归零时死亡
  - 死亡后军队失去英雄加成
  - 英雄不会永久消失

【重生机制】
  - 死亡后需要7天才能重新召唤
  - 重召成本：🌿2000 + 🪨1000 + 专属资源500
  - 重召后英雄等级保留，但装备丢失
```

## 六、标准化英雄编队

### 6.1 编队规则（统一）

```
【编队规则】
  - 英雄可以编入任意军队队列
  - 英雄占据队列中的1个位置
  - 英雄所在队列的属性按英雄属性计算

【编队示例】
  军队：先锋部队
  队列1：🐜 工蚁 ×30
  队列2：🐜 兵蚁 ×20 + 👑 蚁后·琥珀
  队列3：🪰 侦查蚁 ×10
  队列4：空
```

### 6.2 英雄技能使用（统一）

```
【技能使用】
  - 可以在战斗中手动释放
  - 也可以在设置中开启"自动释放"
  - 技能有冷却时间
```
