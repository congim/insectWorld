## 一、大地图系统设计

### 1.1 地图规格

```
【地图尺寸】
  - 标准地图：20×20格（400格）
  - 大服地图：30×30格（900格）
  - 新手地图：10×10格（100格）
  - 每格大小：约50m×50m（微观尺度）

【地图类型】
  - 赛季地图：每赛季随机生成
  - 固定地图：特定活动使用
  - 自定义地图：玩家创作（未来）
```

### 1.2 地块类型

| 地块 | 资源产出 | 行军速度 | 特殊效果 | 占领条件 |
|------|----------|----------|----------|----------|
| 🌿 草地 | 食物+5/分钟 | 1.0× | 开阔视野 | 驻军1个单位 |
| 🌲 森林 | 食物+3/分钟 | 0.8× | 视野-30%，可隐身 | 驻军1个单位 |
| 🪨 岩石 | 矿物质+5/分钟 | 0.7× | 防御+15% | 驻军1个单位 |
| 💧 水源 | 水源+5/分钟 | 0.9× | 附近地块水源+2 | 驻军1个单位 |
| 🌾 农田 | 食物+10/分钟 | 1.1× | 可能触发人类事件 | 驻军1个单位 |
| 🍄 真菌区 | 食物+5/分钟 | 1.0× | 持续回血 | 驻军1个单位 |
| 🏚️ 废墟 | 矿物质+3/分钟 | 0.9× | 探索可获奖励 | 驻军1个单位 |
| 🌸 花田 | 花粉+3/分钟 | 1.0× | 虫族友好 | 驻军1个单位 |
| 🕸️ 腐化区 | 腐质+2/分钟 | 0.8× | 蛆虫族友好 | 驻军1个单位 |
| ⬜ 空白 | 无 | 1.0× | 无 | 需占领才有产出 |

### 1.3 地图渲染

```
【渲染层级】
  Layer 1：地形底色（草地/森林/岩石等）
  Layer 2：地块资源标识
  Layer 3：城市建筑
  Layer 4：军队位置（实时）
  Layer 5：采集队位置（实时）
  Layer 6：事件影响区域
  Layer 7：UI覆盖层

【渲染优化】
  - 视锥剔除：只渲染视野内内容
  - 层级LOD：远处降低细节
  - 动态加载：随镜头移动加载新地块
```

## 二、军队实时移动系统

### 2.1 移动机制

```
【移动计算】
  移动速度 = 基础速度 × 地形修正 × 天气修正 × 科技修正
  
  基础速度：
    极快：2.0格/分钟（侦查蚁、蜻蜓护卫）
    快：1.5格/分钟（工蚁、幼螳、若虫）
    中：1.0格/分钟（兵蚁、成螳、战士蜂）
    慢：0.7格/分钟（大颚蚁、甲壳兵、重甲单位）
    极慢：0.5格/分钟（泰坦甲虫、腐化虫王）
  
  地形修正：
    草地：1.0×
    森林：0.8×（减速30%，但可隐身）
    岩石：0.7×（减速30%）
    水源：0.9×（减速10%）
    农田：1.1×（加速10%，但易被发现）
    城墙范围：0.5×（攻城严重减速）
  
  天气修正：
    晴天：1.0×
    暴雨：0.8×（地面单位）
    狂风：0.7×（飞行单位）
    野火：0.6×（所有单位）
  
  科技修正：
    联盟疾行Lv.1：+10%
    挖洞技术Lv.1：+30%（地下）
```

### 2.2 路径规划

```
【路径规划算法】
  - A*算法：寻找最短路径
  - 动态避障：避开敌方军队
  - 地形权重：优先选择快速地形
  
【路径显示】
  - 绿色：安全路径（无敌方军队）
  - 黄色：潜在风险（有敌方军队但可绕过）
  - 红色：危险路径（需经过敌方军队）
  
【路径变更】
  - 玩家可随时变更目标
  - 有5分钟冷却时间
  - 变更时重新规划路径
```

### 2.3 移动状态机

```
【状态定义】
  状态：待命/行军/巡逻/驻守/返回/战斗/被伏击
  
  状态转换：
    待命 → 行军（玩家指令）
    行军 → 战斗（遭遇敌人）
    战斗 → 撤退（玩家指令/败方）
    撤退 → 返回（撤退中）
    返回 → 待命（到达城市）
    待命 → 巡逻（玩家指令）
    巡逻 → 行军（玩家指令）
    巡逻 → 战斗（遭遇敌人）
    待命 → 驻守（玩家指令）
    驻守 → 行军（玩家指令）
    驻守 → 战斗（敌人进入范围）
    行军 → 被伏击（采集队被拦截）
    被伏击 → 战斗（战斗状态）
```

### 2.4 实时位置更新

```
【位置更新频率】
  - 服务器：每1秒更新一次
  - 客户端：每0.5秒渲染一次
  - 网络同步：每2秒同步一次
  
【位置插值】
  - 客户端使用线性插值平滑移动
  - 避免位置跳跃
  - 预测性渲染（预测下一帧位置）
  
【延迟处理】
  - 网络延迟：最多500ms
  - 客户端预测：提前渲染预计位置
  - 服务器校正：修正实际位置
```

## 三、实时战斗系统

### 3.1 战斗触发

```
【战斗触发条件】
  - 军队移动到敌方军队所在地块 → 自动战斗
  - 军队移动到敌方城市周围1格 → 开始攻城
  - 采集队被敌方军队拦截 → 伏击战
  - 玩家手动攻击敌方地块 → 战斗
  
【战斗准备】
  - 双方军队进入战斗状态
  - 战斗开始前有5秒准备时间（可撤退）
  - 准备时间结束后自动开始战斗
```

### 3.2 战斗演算

```
【伤害计算】
  伤害 = 攻击 × (1 - 防御/100) × 克制系数 × 随机(0.9-1.1) × 特殊加成
  
  攻击 = 基础攻击 × (1 + 等级×0.1) × (1 + 种族攻击修正) × (1 + 科技攻击修正)
  
  防御 = 基础防御 × (1 + 等级×0.1) × (1 + 种族防御修正) × (1 + 科技防御修正)
  
  克制系数：
    优势：1.5×
    劣势：0.7×
    正常：1.0×
  
  特殊加成：
    首击暴击：×2.0（螳螂族特性）
    攻城加成：×1.5（泰坦甲虫）
    伏击加成：×1.5（森林地形）
    中毒减防：-20%防御（中毒状态）
    腐蚀减防：-30%防御（腐蚀状态）

【战斗阶段】
  ① 接近阶段：双方军队向对方移动（实时）
  ② 射程阶段：进入射程后开始攻击（每10秒一次）
  ③ 近战阶段：进入melee范围后近战攻击
  ④ 结束阶段：一方撤退或全灭
```

### 3.3 战斗UI

```
【小地图】
  - 显示战斗位置
  - 红色闪烁表示战斗
  - 点击可跳转到战斗位置
  
【战斗详情】
  - 实时显示战损
  - 实时显示伤害数字
  - 可暂停/快进/回放
  
【战斗统计】
  - 总伤害输出
  - 总受到伤害
  - 击杀数
  - 战损比
```

## 五、采集队实时系统

### 5.1 采集队移动

```
【采集队移动】
  - 采集队在大地图上实时移动
  - 移动速度 = 最慢单位的速度
  - 可被敌方军队拦截
  - 可派军队护送
  
【采集队UI】
  - 小地图上显示采集队位置（蓝色标记）
  - 点击可查看详情
  - 可手动指令（撤回/改变目标）
```

### 5.2 伏击系统

```
【伏击触发】
  - 敌方军队移动到采集队路径上
  - 敌方军队速度 > 采集队速度
  - 距离 < 2格时触发伏击
  
【伏击效果】
  - 采集队与敌方军队战斗
  - 败方：资源50%被掠夺，采集队可能全灭
  - 胜方：保护资源，可能追击
  
【预防措施】
  - 派军队护送采集队
  - 选择安全路线
  - 缩短采集时间
  - 增加采集队数量（分散风险）
```

## 六、实时事件系统

### 6.1 天气事件

```
【天气系统】
  - 每10分钟检查一次天气
  - 天气影响整张地图
  - 天气持续2-60秒
  - 有预警时间（1-5分钟）

【天气类型】
  - 🌧️ 暴雨：地面单位移动-50%，低洼地区被淹
  - ☀️ 干旱：水源产出-50%，植物枯萎
  - 💨 狂风：飞行单位失控，轻型单位被吹走
  - 🔥 野火：森林区域每秒30伤害，森林变废墟
```

### 6.2 人类活动事件

```
【人类活动】
  - 每小时1-3次随机触发
  - 影响特定区域（5-20格）
  - 有预警时间（无/1-3分钟）

【活动类型】
  - 🧴 农药喷洒：范围内每秒20伤害+中毒
  - 👟 人类踩踏：瞬间毁灭范围内所有单位
  - 🌱 园艺活动：改变地形，移除资源点
  - 📸 昆虫爱好者：随机抓走高级单位
```

### 6.3 天灾事件

```
【天灾系统】
  - 每赛季2-3次
  - 影响大范围（30%地图）
  - 毁灭性打击

【天灾类型】
  - 🌪️ 龙卷风：路径上所有单位被卷走
  - 👟 巨型踩踏：随机5-10格瞬间毁灭
  - 🧴 大规模农药：30%地图每秒30伤害
```

## 八、实时性能优化

### 8.1 服务器优化

```
【服务器架构】
  - 主服务器：处理核心逻辑
  - 区域服务器：处理地图分区
  - 战斗服务器：处理实时战斗
  - 聊天服务器：处理社交功能
  
【负载均衡】
  - 动态分配服务器
  - 热点区域分流
  - 战斗区域隔离
```

### 8.2 客户端优化

```
【渲染优化】
  - 视锥剔除：只渲染视野内内容
  - 层级LOD：远处降低细节
  - 动态加载：随镜头移动加载新地块
  
【网络优化】
  - 状态同步：只同步状态变化
  - 预测渲染：客户端预测移动
  - 差量更新：只更新变化部分
```

## 九、实时移动系统设计总结

| 系统 | 核心机制 | 设计目标 |
|------|----------|----------|
| 大地图系统 | 20×20网格，实时渲染 | 提供广阔战场 |
| 军队移动系统 | 实时位置更新，路径规划 | 增强策略深度 |
| 战斗演算系统 | 实时伤害计算，战斗回放 | 增强战斗体验 |
| 采集队系统 | 实时移动，伏击机制 | 增加风险与策略 |
| 事件系统 | 实时触发，影响全局 | 增加动态性 |
| 社交系统 | 实时聊天，战争状态 | 增强社交体验 |
| 性能优化 | 服务器/客户端优化 | 保证流畅体验 |
