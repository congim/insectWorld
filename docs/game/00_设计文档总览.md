# 昆虫世界设计总览

> 状态：提案
>
> 定位：以微观昆虫生态为题材、强调大世界行军与领土竞争的异步 SLG。
>
> 说明：本目录只描述昆虫世界游戏包，不定义通用引擎架构。

## 核心体验

玩家经营一个昆虫族群，通过巢穴建设、单位培育、资源采集和地图行军扩张生存空间，并在动态生态与联盟竞争中形成长期策略。

首个可玩版本聚焦：

- 一个可理解的昆虫种族；
- 建造、生产、采集、行军、战斗和结算闭环；
- 小规模持久世界与断线恢复；
- 题材内容全部来自游戏包，专属机制通过扩展实现。

七种族、复杂联盟、完整赛季、世界 Boss 和全量数值表均是后续内容，不是首个闭环的前置条件。

归类规则以[产品与平台边界](../product/产品与平台边界.md)为准，服务端实现以[目标架构](../architecture/目标架构.md)为准。

## 首个垂直切片

```text
创建蚁族玩家
  → 建造并升级一个巢室
  → 消耗资源训练工蚁与战斗单位
  → 派遣队伍到相邻地块采集
  → 遭遇一个中立生物并触发战斗
  → 结算伤兵、战利品和资源
  → 保存状态，重启后继续
```

该切片只需要一张小地图、一套基础资源、少量单位和一个敌人。任何不服务这条链路的设计默认后置。

## 内容冻结规则

- 玩法进入实现前必须从“内容池”裁剪成明确版本范围；
- 数值表默认是策划假设，进入游戏包配置后才成为可测试契约；
- 同一机制若与 `docs/engine/` 冲突，引擎契约负责机制，本文档负责题材表现；
- 首个闭环完成前，不继续扩写七种族的完整内容量。
