## 一、游戏定位

### 核心体验
传统SLG的**领土占领+实时行军+联盟社交**，移植到微观昆虫世界，**大世界实时军队移动**。

### 核心创新
```
【实时移动系统】
  - 所有军队在大地图上实时移动
  - 玩家可随时观察军队位置
  - 军队移动受地形/天气/事件影响
  - 实时战斗演算，可观看战斗过程
```

## 三、实时移动系统设计

### 3.1 大地图结构

```
【地图规格】
  - 标准地图：20×20格（400格）
  - 大服地图：30×30格（900格）
  - 新手地图：10×10格（100格）
  - 每格大小：约50m×50m（微观尺度）

【地图渲染】
  - 俯视视角，可缩放
  - 实时显示所有军队位置
  - 实时显示地块控制状态
  - 实时显示事件影响区域
```

### 3.2 军队实时移动

```
【移动机制】
  - 军队在大地图上实时移动
  - 移动速度 = 基础速度 × 地形修正 × 天气修正
  - 每30秒移动1格（基准）
  - 玩家可随时观察军队位置

【路径规划】
  - 系统自动规划最短路径
  - 玩家可手动选择路线
  - 路径显示在地图上（绿色=安全，红色=危险）

【移动状态】
  - 行军中：实时显示位置，不可变更目标（有冷却）
  - 巡逻中：在指定地块周围实时移动
  - 驻守中：停留在指定地块
  - 战斗时：进入战斗状态，停止移动
```

### 3.3 实时战斗系统

```
【战斗触发】
  - 军队移动到敌方军队所在地块 → 自动进入战斗
  - 军队移动到敌方城市周围1格 → 开始攻城
  - 采集队被敌方军队拦截 → 触发伏击战

【战斗演算】
  - 实时计算伤害
  - 实时显示战损
  - 可观看战斗回放
  - 战斗结果实时更新

【战斗UI】
  - 小地图显示战斗位置
  - 战斗详情弹窗
  - 战损统计实时显示
```

## 五、核心SLG机制详表

### 5.1 地块占领机制

```
【占领流程】
  ① 军队移动到空白地块（非战斗状态）
  ② 停留10秒（可被敌人打断）
  ③ 地块变为"己方控制"
  ④ 部署采集队后开始产出资源

【失守条件】
  - 没有军队驻守超过5分钟 → 地块变为"无人控制"
  - 被敌方军队攻占 → 地块变为"敌方控制"
  - 地块被外部事件摧毁 → 地块变为"废墟"
```

### 5.2 采集队机制

```
【采集队配置】
  - 最多5个单位（建议全部是工蚁/采集者类兵种）
  - 移动速度 = 最慢单位的速度
  - 载重：最多200🌿/150💧/100🪨/50专属

【采集流程】
  ① 选择目标地块（必须在己方控制范围内）
  ② 采集队移动到该地块（耗时 = 距离 × 30秒/格 / 速度）
  ③ 开始采集（每10秒产出资源，存入采集队载重）
  ④ 载重满或手动结束，采集队返回城市
  ⑤ 资源进入城市存储

【伏击机制】
  - 敌方军队移动到采集队路径上触发
  - 败方：资源50%被掠夺，采集队可能全灭
  - 胜方：保护资源，可能追击
```

### 5.3 实时行军机制

```
【行军时间】
  时间 = 距离 × 30秒 / 速度 × 地形修正 × 天气修正

【地形修正】
  草地：1.0× | 森林：0.8× | 岩石：0.7×
  水源：0.9× | 农田：1.1× | 城墙：0.5×

【实时移动】
  - 军队在大地图上实时移动
  - 玩家可随时观察军队位置
  - 移动途中可被拦截
  - 到达目的地后自动进入战斗或驻守
```

### 5.4 实时战斗机制

```
【战斗触发】
  - 军队移动到敌方军队所在地块 → 自动战斗
  - 军队移动到敌方城市周围1格 → 开始攻城
  - 采集队被敌方军队拦截 → 战斗

【伤害公式】
  伤害 = 攻击 × (1 - 防御/100) × 克制系数 × 随机(0.9-1.1)

【战斗结果】
  - 胜方：追击可选（速度+50%）
  - 败方：撤退（保留20%兵力）
  - 平手：双方各保留50%兵力
```
