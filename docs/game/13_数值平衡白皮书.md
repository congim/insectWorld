## 一、数值平衡核心原则

### 1.1 平衡三角

```
        速度
       /    \
      /      \
     /   平衡  \
    /     |     \
   /_____|______\
  强度    成本
```

- **强度**：战斗力高低
- **速度**：行军/生产/响应速度
- **成本**：资源消耗

**原则**：任何兵种必须在三角中占两角，不能三角全优

### 1.2 平衡容忍度

| 维度 | 容忍范围 | 说明 |
|------|----------|------|
| 兵种强度 | ±15% | 同类型兵种强度差异不超过15% |
| 兵种成本 | ±20% | 同类型兵种成本差异不超过20% |
| 种族特性 | ±10% | 种族特性数值差异不超过10% |
| 英雄技能 | ±20% | 英雄技能数值差异不超过20% |

## 二、兵种数值平衡

### 2.1 基础属性公式

```
【血量公式】
  血量 = 类型基础 × (1 + 等级 × 0.1) × (1 + 种族防御修正)
  
  类型基础：
    轻甲：30 | 重甲：80 | 飞行：40 | 远程：35 | 刺客：30 | 支援：50

【攻击公式】
  攻击 = 类型基础 × (1 + 等级 × 0.1) × (1 + 种族攻击修正)
  
  类型基础：
    轻甲：5 | 重甲：10 | 飞行：8 | 远程：8 | 刺客：12 | 支援：5

【防御公式】
  防御 = 类型基础 × (1 + 等级 × 0.1) × (1 + 种族防御修正)
  
  类型基础：
    轻甲：2 | 重甲：20 | 飞行：3 | 远程：3 | 刺客：3 | 支援：5

【速度公式】
  速度 = 类型基础 × 种族速度修正
  
  类型基础：
    快：1.5× | 极快：2.0× | 中：1.0× | 慢：0.7× | 极慢：0.5×
```

### 2.2 伤害计算公式

```
【基础伤害】
  伤害 = 攻击 × (1 - 防御/100) × 克制系数 × 随机(0.9-1.1)

【克制系数】
  优势：1.5× | 劣势：0.7× | 正常：1.0×

【特殊加成】
  首击暴击：×2.0（螳螂族特性）
  攻城加成：×1.5（泰坦甲虫）
  伏击加成：×1.5（森林地形）
  种族特性：根据具体特性计算
```

### 2.3 兵种平衡测试场景

```
【场景1：100轻甲 vs 50重甲】
  轻甲总攻击 = 100 × 5 × 1.5（克制）= 750
  重甲总防御 = 50 × 20 = 1000
  预期结果：轻甲胜（克制关系主导）

【场景2：50飞行 vs 100轻甲】
  飞行总攻击 = 50 × 8 × 1.5（克制）= 600
  轻甲总防御 = 100 × 2 = 200
  预期结果：飞行胜（克制+数量优势）

【场景3：80重甲 vs 80远程】
  重甲总攻击 = 80 × 10 × 1.5（克制）= 1200
  远程总防御 = 80 × 3 = 240
  预期结果：重甲胜（接近后无敌）

【场景4：60刺客 vs 100群体】
  刺客总攻击 = 60 × 12 × 1.5（克制）= 1080
  群体总防御 = 100 × 2 = 200
  预期结果：刺客胜（先手爆发）

【场景5：50远程 vs 50重甲】
  远程总攻击 = 50 × 8 = 400
  重甲总防御 = 50 × 20 = 1000
  预期结果：远程胜（射程优势，风筝战术）
```

## 三、资源数值平衡

### 3.1 资源产出公式

```
【采集队产出】
  产出 = 地块基础产出 × 采集效率 × 地形修正
  
  地块基础产出：
    草地：5🌿/10秒
    农田：10🌿/10秒
    岩石：5🪨/10秒
    水源：5💧/10秒
    花田：2🌸/10秒
    
  采集效率：
    采集营Lv.1：100%
    采集营Lv.2：120%
    采集营Lv.3：140%
    采集营Lv.4：160%
    采集营Lv.5：180%

【自产建筑产出】
  产出 = 建筑等级 × 基础系数 × (1 + 科技加成)
  
  基础系数：
    信息素腺体：1🧬/分钟
    花田：2🌸/分钟
    蜕壳场：1🦴/分钟
    蜂王浆产房：1.5🍯/分钟
    狩猎场：1⚡/击杀
    迁徙谷物田：2🌾/分钟
    腐食场：1🦠/分钟
```

### 3.2 资源消耗平衡

```
【维持消耗】
  食物 = 人口 × 1/分钟
  水源 = 人口 × 0.5/分钟
  
【生产消耗】
  基础兵种：🌿30-50
  进阶兵种：🌿60-100
  重甲兵种：🌿100-150
  飞行兵种：🌿100-150 + ☀️30-50
  英雄单位：🌿300-500
  
【建筑消耗】
  升级成本 = 基础成本 × (1 + 等级 × 0.5)
```

## 四、战斗数值平衡

### 4.1 军队战斗力计算

```
【战斗力公式】
  战斗力 = Σ(单位血量 × 攻击 × 克制系数) / 100
  
【示例计算】
  军队：10工蚁 + 10兵蚁
  工蚁战斗力 = 30 × 5 / 100 = 1.5 × 10 = 15
  兵蚁战斗力 = 60 × 12 / 100 = 7.2 × 10 = 72
  总战斗力 = 15 + 72 = 87
```

### 4.2 战斗结果预测

```
【胜负判断】
  胜方战斗力 > 败方战斗力 × 1.2（加成）
  
【战损计算】
  战损率 = 败方战斗力 / 胜方战斗力 × 0.8
  保留兵力 = 败方总兵力 × (1 - 战损率) × 0.2
```

## 五、种族平衡测试

### 5.1 对抗测试矩阵

```
【蚁族 vs 其他种族】
  vs 虫族：蚁族胜（地面压制飞行）
  vs 甲虫族：平手（数量 vs 防御）
  vs 蜂族：蚁族胜（集群压制远程）
  vs 螳螂族：螳螂族胜（刺客先手）
  vs 蝗虫族：蚁族胜（克制关系）
  vs 蛆虫族：蚁族胜（克制关系）

【虫族 vs 其他种族】
  vs 蚁族：虫族胜（飞行优势）
  vs 甲虫族：虫族胜（飞行克制重甲）
  vs 蜂族：平手（都是远程）
  vs 螳螂族：虫族胜（飞行克制刺客）
  vs 蝗虫族：虫族胜（飞行克制群体）
  vs 蛆虫族：虫族胜（飞行克制地面）

【甲虫族 vs 其他种族】
  vs 蚁族：平手
  vs 虫族：甲虫族胜（重甲克制飞行）
  vs 蜂族：甲虫族胜（重甲克制远程）
  vs 螳螂族：平手
  vs 蝗虫族：甲虫族胜（重甲克制群体）
  vs 蛆虫族：甲虫族胜（重甲克制地面）
```

### 5.2 平衡修正原则

```
【修正方向】
  - 胜率 > 60%：削弱该种族或加强被克制种族
  - 胜率 < 40%：加强该种族或削弱克制种族
  - 胜率 45-55%：平衡，无需调整
  
【修正幅度】
  - 小幅修正：±5%
  - 中幅修正：±10%
  - 大幅修正：±15%（需重新测试）
```

## 六、平衡性检查清单

### 6.1 兵种平衡检查

- [ ] 同类型兵种强度差异 ≤ 15%
- [ ] 同类型兵种成本差异 ≤ 20%
- [ ] 每种兵种都有明确克制关系
- [ ] 没有绝对最优兵种
- [ ] 数量优势可以弥补质量劣势

### 6.2 种族平衡检查

- [ ] 每种种族胜率在45-55%之间
- [ ] 每种种族有明确优势期和劣势期
- [ ] 没有绝对最优种族
- [ ] 种族特性数值差异 ≤ 10%

### 6.3 英雄平衡检查

- [ ] 同定位英雄强度差异 ≤ 20%
- [ ] 每种英雄技能都有明确用途
- [ ] 没有绝对最强英雄
- [ ] 英雄技能冷却时间合理
