## 一、标准化联盟基础系统

### 1.1 创建联盟（统一）

```
【创建条件】
  - 城市达到Lv.2
  - 消耗🌿2000 + 🪨1000
  - 联盟名最多12个字符

【联盟信息】
  - 联盟名
  - 联盟标志（可选）
  - 联盟宣言（最多100字）
  - 联盟等级
  - 成员数量（最多10人）
```

### 1.2 联盟等级（统一）

## 二、标准化联盟领土系统

### 2.1 领土规则（统一）

```
【联盟领土】
  - 联盟成员的城市周围3格自动成为"联盟领土"
  - 联盟领土内的地块，所有成员都可以部署采集队
  - 联盟领土外的地块，只有城市所属成员可以部署

【领土收益分配】
  - 联盟领土内的资源产出：60%归所属成员，40%进入联盟国库
  - 联盟国库用于：联盟科技研发、联盟战争奖励、成员援助
```

### 2.2 贡献度系统（统一）

| 行为 | 贡献度 |
|------|--------|
| 占领地块 | +10/块 |
| 击杀敌人 | +5/单位 |
| 参与联盟战争 | +20/场 |
| 捐赠资源 | +1/100资源 |

## 四、标准化联盟战争系统

### 4.1 战争触发（统一）

```
【宣战条件】
  - 两个联盟可以宣战
  - 需要联盟长发起，联盟成员投票（50%以上通过）
  - 战争持续7天
```

### 4.2 计分规则（统一）

| 行为 | 得分 |
|------|------|
| 攻占一块敌方领土 | +10分 |
| 摧毁敌方城市建筑 | +5分 |
| 击杀敌方军队 | +2分/单位 |
| 防守成功（击退攻击） | +1分 |
| 占领敌方城市中心 | +100分 |

### 4.3 战争奖励（统一）

| 排名 | 奖励 |
|------|------|
| 获胜 | 🪙5000赛季货币 + 🏆联盟战争胜利徽章 |
| 失败 | 🪙2000赛季货币 + 🏆联盟战争参与徽章 |
| MVP | 🎨传说皮肤 + 🪙3000赛季货币 |

## 五、标准化联盟互助系统

### 5.1 资源援助（统一）

```
【援助规则】
  - 联盟成员可以互相赠送资源（每天限额）
  - 援助量 = 援助者存储量 × 5%
  - 每天限额 = 联盟等级 × 100资源
```

### 5.2 军队援助（统一）

```
【援助规则】
  - 联盟成员可以请求其他成员派兵支援
  - 被请求方可以在自己领土内或联盟领土内响应
  - 支援军队在任务完成后自动返回
```

### 5.3 建造援助（统一）

```
【援助规则】
  - 联盟成员可以互相加速建筑建造（每天限额）
  - 加速量 = 联盟等级 × 10%
```

## 十、设计优势

### 10.1 开发效率

```
【底层代码】
  - 联盟系统：1套代码
  - 领土系统：1套代码
  - 战争系统：1套代码
  - 互助系统：1套代码

【配置数据】
  - 联盟等级：6条配置
  - 联盟科技：8条配置
  - 战争计分：5条配置
  - 互助规则：3条配置
```

### 10.2 平衡性控制

```
【平衡重点】
  - 联盟领土范围：固定3格
  - 联盟科技加成：固定5-20%
  - 战争计分：固定分值
  - 资源援助：固定5%比例
```
