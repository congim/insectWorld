## 一、兵种属性标准公式

### 1.1 基础属性公式

```
【血量】
  血量 = 类型基础血量 × (1 + 等级 × 0.1) × (1 + 种族防御修正) × (1 + 科技防御修正)
  
  类型基础血量：
    轻甲：30 | 重甲：80 | 飞行：40 | 远程：35 | 刺客：30 | 支援：50

【攻击】
  攻击 = 类型基础攻击 × (1 + 等级 × 0.1) × (1 + 种族攻击修正) × (1 + 科技攻击修正)
  
  类型基础攻击：
    轻甲：5 | 重甲：10 | 飞行：8 | 远程：8 | 刺客：12 | 支援：5

【防御】
  防御 = 类型基础防御 × (1 + 等级 × 0.1) × (1 + 种族防御修正) × (1 + 科技防御修正)
  
  类型基础防御：
    轻甲：2 | 重甲：20 | 飞行：3 | 远程：3 | 刺客：3 | 支援：5

【速度】
  速度 = 类型基础速度 × 种族速度修正 × 科技速度修正
  
  类型基础速度：
    极快：2.0× | 快：1.5× | 中：1.0× | 慢：0.7× | 极慢：0.5×

【射程】
  近战：1格 | 远程：2-4格 | 飞行：2-3格
```

### 1.2 兵种等级属性加成

```
【等级加成】
  Lv.1：100%
  Lv.2：110%
  Lv.3：125%
  Lv.4：140%
  Lv.5：160%
  
【升级条件】
  兵营Lv.2解锁Lv.2兵种
  兵营Lv.3解锁Lv.3兵种
  兵营Lv.4解锁Lv.4兵种
  兵营Lv.5解锁Lv.5兵种
```

## 二、兵种类型详细定义

### 2.1 轻甲单位

```
【特点】
  - 速度快，成本低
  - 防御低，血量低
  - 数量多，适合消耗

【代表兵种】
  - 蚁族：工蚁、兵蚁
  - 虫族：幼虫侦察兵
  - 蝗虫族：若虫、成虫蝗

【克制关系】
  - 克制：群体、远程
  - 被克制：重甲、刺客
```

### 2.2 重甲单位

```
【特点】
  - 防御高，血量高
  - 速度慢，成本高
  - 适合正面推进

【代表兵种】
  - 蚁族：大颚蚁、巨颚将军
  - 甲虫族：甲壳兵、重装锤甲虫
  - 蝗虫族：蝗群领主

【克制关系】
  - 克制：轻甲、飞行
  - 被克制：远程、刺客
```

### 2.3 飞行单位

```
【特点】
  - 可跨越地形
  - 被地面单位攻击命中率-30%
  - 需要太阳能生产

【代表兵种】
  - 蚁族：侦查蚁
  - 虫族：成虫飞行兵、幻影蝶
  - 蜂族：侦察蜂

【克制关系】
  - 克制：轻甲、群体
  - 被克制：重甲、远程
```

### 2.4 远程单位

```
【特点】
  - 射程2-4格
  - 近距离弱
  - 持续输出

【代表兵种】
  - 蜂族：工蜂、战士蜂、毒蜂
  - 虫族：花蜜采集者

【克制关系】
  - 克制：重甲、刺客
  - 被克制：轻甲、飞行
```

### 2.5 刺客单位

```
【特点】
  - 高爆发，低血量
  - 首次攻击必定暴击（螳螂族）
  - 适合伏击

【代表兵种】
  - 螳螂族：幼螳、成螳、暗影螳螂
  - 虫族：幻影蝶、蛾影刺客

【克制关系】
  - 克制：远程、群体
  - 被克制：重甲、轻甲
```

### 2.6 支援单位

```
【特点】
  - 治疗/增益
  - 战斗力弱
  - 保护核心

【代表兵种】
  - 蚁族：蚁后侍卫
  - 蜂族：蜂后侍卫
  - 蛆虫族：重生者、腐化领主

【克制关系】
  - 无明确克制
  - 依赖保护
```

## 五、兵种生产系统详细设计

### 5.1 生产队列

```
【生产规则】
  - 每个兵营同时只能生产1种兵种
  - 可使用加速道具缩短生产时间
  - 生产完成的单位进入"预备队"

【预备队系统】
  - 预备队容量 = 城市等级 × 10
  - 超出容量后需要编入军队
  - 预备队中的单位可随时编入军队

【生产时间】
  基础兵种：30秒
  进阶兵种：60秒
  重甲兵种：90秒
  飞行兵种：75秒
  英雄单位：120秒（一次性，不可加速）
```

### 5.2 军队编成

```
【军队结构】
  - 一支军队 = 最多4个队列
  - 每队列最多50个同种单位
  - 英雄可以编入任意队列

【编队示例】
  军队：先锋部队
  队列1：🐜 工蚁 ×30
  队列2：🐜 兵蚁 ×20 + 👑 蚁后·琥珀
  队列3：🪰 侦查蚁 ×10（飞行）
  队列4：空

【英雄编队】
  - 英雄占据队列中的1个位置
  - 英雄所在队列的属性按英雄属性计算
  - 英雄技能可在战斗中手动释放
```

## 六、兵种升级系统详细设计

### 6.1 兵种等级

```
【等级加成】
  Lv.1：100%
  Lv.2：110%
  Lv.3：125%
  Lv.4：140%
  Lv.5：160%
  
【升级条件】
  兵营Lv.2解锁Lv.2兵种
  兵营Lv.3解锁Lv.3兵种
  兵营Lv.4解锁Lv.4兵种
  兵营Lv.5解锁Lv.5兵种
```

### 6.2 兵种进阶

```
【进阶条件】
  工蚁 → 侦查蚁：采集营Lv.2，获得飞行能力
  兵蚁 → 突进兵蚁：兵营Lv.2，冲锋加成
  成螳 → 暗影螳螂：兵营Lv.2，获得隐身能力
  蛆虫I → 蛆虫II：蛹化祭坛，属性全面提升

【进阶效果】
  - 属性提升：血量+20%，攻击+15%，防御+10%
  - 特殊能力：获得新技能或特性
  - 成本增加：生产成本+30%
```

## 七、兵种平衡检查

### 7.1 平衡检查清单

```
【同类型兵种检查】
  - [ ] 血量差异 ≤ 15%
  - [ ] 攻击差异 ≤ 15%
  - [ ] 防御差异 ≤ 15%
  - [ ] 成本差异 ≤ 20%
  - [ ] 生产时间差异 ≤ 20%

【跨类型兵种检查】
  - [ ] 每种类型都有明确优势场景
  - [ ] 没有绝对最优兵种
  - [ ] 克制关系清晰
  - [ ] 数量优势可以弥补质量劣势
```

### 7.2 平衡测试场景

```
【场景1：同等成本对比】
  🌿100成本：
    蚁族：2个大颚蚁 或 3个兵蚁
    测试：2大颚蚁 vs 3兵蚁 → 大颚蚁胜（重甲克制）

【场景2：同等数量对比】
  100单位：
    100轻甲 vs 100重甲 → 轻甲胜（克制关系）
    100飞行 vs 100轻甲 → 飞行胜（机动优势）
    100远程 vs 100重甲 → 远程胜（射程优势）

【场景3：混合军队对比】
  50轻甲+50重甲 vs 100远程 → 混合胜（互补）
  30飞行+70轻甲 vs 100重甲 → 混合胜（克制+数量）
```
