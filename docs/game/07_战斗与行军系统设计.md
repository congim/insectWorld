## 一、行军系统详细设计

### 1.1 行军时间计算（完整公式）

```
【基础行军时间】
  基础时间 = 距离（格数）× 30秒

【速度修正】
  速度修正 = 单位速度 × 种族速度修正 × 科技速度修正
  
  单位速度：
    极快：2.0×（侦察蚁、蜻蜓护卫）
    快：1.5×（工蚁、幼螳、若虫）
    中：1.0×（兵蚁、成螳、战士蜂）
    慢：0.7×（大颚蚁、甲壳兵、重甲单位）
    极慢：0.5×（泰坦甲虫、腐化虫王）
  
  种族速度修正：
    蚁族：+0%
    虫族：+5%（飞行单位）
    甲虫族：-5%
    蜂族：+0%
    螳螂族：+10%
    蝗虫族：+10%
    蛆虫族：-10%
  
  科技速度修正：
    联盟疾行Lv.1：+10%
    联盟疾行Lv.2：+20%
    挖洞技术Lv.1：+30%（地下）

【地形修正】
  地形修正 = 地形系数 × 天气系数
  
  地形系数：
    草地：1.0×
    森林：0.8×（减速30%，但可隐身）
    岩石：0.7×（减速30%）
    水源：0.9×（减速10%）
    农田：1.1×（加速10%，但易被发现）
    真菌区：1.0×
    废墟：0.9×
    腐化区：0.8×（减速，但蛆虫族+20%）
    城墙范围：0.5×（攻城严重减速）
  
  天气系数：
    晴天：1.0×
    暴雨：0.8×（地面单位）
    狂风：0.7×（飞行单位）
    野火：0.6×（所有单位）
```

### 1.2 行军状态机

```
【状态定义】
  状态：行军/巡逻/驻守/返回/战斗/待命
  
  状态转换：
    待命 → 行军（玩家指令）
    行军 → 战斗（遭遇敌人）
    战斗 → 撤退（玩家指令/败方）
    撤退 → 返回（撤退中）
    返回 → 待命（到达城市）
    待命 → 巡逻（玩家指令）
    巡逻 → 行军（玩家指令）
    巡逻 → 战斗（遭遇敌人）
    待命 → 驻守（玩家指令）
    驻守 → 行军（玩家指令）
    驻守 → 战斗（敌人进入范围）
```

### 1.3 行军中断机制

```
【中断条件】
  - 遭遇敌方军队（距离<2格）
  - 玩家手动中止（5分钟冷却）
  - 城市被攻陷（强制返回）
  - 外部事件影响（龙卷风卷走）

【中断处理】
  - 遭遇战斗：自动进入战斗状态
  - 手动中止：军队原地待命
  - 强制返回：军队自动返回城市
```

## 二、战斗系统详细设计

### 2.1 伤害计算（完整公式）

```
【单单位伤害】
  伤害 = 攻击 × (1 - 防御/100) × 克制系数 × 随机(0.9-1.1) × 特殊加成
  
  攻击 = 基础攻击 × (1 + 等级×0.1) × (1 + 种族攻击修正) × (1 + 科技攻击修正)
  
  防御 = 基础防御 × (1 + 等级×0.1) × (1 + 种族防御修正) × (1 + 科技防御修正)
  
  克制系数：
    优势：1.5×
    劣势：0.7×
    正常：1.0×
  
  特殊加成：
    首击暴击：×2.0（螳螂族特性）
    攻城加成：×1.5（泰坦甲虫）
    伏击加成：×1.5（森林地形）
    中毒减防：-20%防御（中毒状态）
    腐蚀减防：-30%防御（腐蚀状态）
```

### 2.2 战斗阶段详细

```
【阶段1：接近阶段】
  - 双方军队向对方移动
  - 移动速度 = 速度 × 地形修正 × 天气修正
  - 每30秒移动1格
  - 进入射程前无伤害

【阶段2：射程阶段】
  - 进入射程后开始攻击
  - 远程单位：射程2-4格
  - 近战单位：射程1格
  - 每10秒攻击一次
  - 飞行单位对地面单位命中率-30%

【阶段3：近战阶段】
  - 进入melee范围（1格）
  - 远程单位转为近战（伤害-50%）
  - 近战单位正常攻击
  - 飞行单位无法进入近战

【阶段4：结束阶段】
  - 一方兵力≤20% → 撤退
  - 一方兵力=0 → 全灭
  - 双方兵力都>20% → 平手
```

### 2.3 战损计算

```
【战损公式】
  战损率 = 败方战斗力 / 胜方战斗力 × 0.8
  
  战斗力 = Σ(单位血量 × 攻击 × 克制系数) / 100
  
【撤退计算】
  保留兵力 = 败方总兵力 × (1 - 战损率) × 0.2
  
  示例：
    胜方战斗力 = 1000
    败方战斗力 = 600
    战损率 = 600 / 1000 × 0.8 = 0.48
    保留兵力 = 100 × (1 - 0.48) × 0.2 = 10.4 → 10单位
    
【追击计算】
  追击速度 = 胜方速度 × 1.5
  追击距离 = 5格
  追击时间 = 5 / 1.5 = 3.3秒
```

## 三、攻城系统详细设计

### 3.1 城墙属性

```
【城墙基础属性】
  血量 = 500 × 等级
  护甲 = 10% × 等级
  
【城墙防御】
  刺塔伤害 = 15 × 刺塔数量 × (1 + 等级×0.2)
  城墙回复 = 工程统领技能修复50%血量
```

### 3.2 攻城伤害

```
【攻城伤害公式】
  伤害 = 攻击 × 攻城系数 × (1 - 护甲/100) × 随机(0.9-1.1)
  
  攻城系数：
    泰坦甲虫：1.5×
    挖掘甲虫：1.2×（可绕过城墙）
    普通单位：1.0×
    
【攻城速度】
  摧毁时间 = 城墙血量 / 攻城伤害/10秒
```

### 3.3 攻城战术

```
【攻击方战术】
  1. 集中火力攻击城墙一点
  2. 使用挖掘甲虫绕过城墙
  3. 分兵骚扰，分散防守注意力
  4. 使用飞行单位空投到城内

【防守方战术】
  1. 加固城墙（升级城墙）
  2. 布置刺塔覆盖城墙范围
  3. 使用陷阱坑拖延敌人
  4. 派军队从侧翼袭击攻击方
```

## 四、特殊战斗机制

### 4.1 伏击战

```
【触发条件】
  - 隐身单位在森林中
  - 敌方单位进入伏击范围（3格）
  - 伏击方主动触发

【伏击效果】
  - 伏击方：首次攻击伤害+50%
  - 被伏击方：第一轮攻击命中率-30%
  - 伏击方优先攻击
  
【伏击后】
  - 进入正常战斗流程
  - 伏击效果仅影响第一轮
```

### 4.2 追击战

```
【触发条件】
  - 战斗胜利后，胜方选择追击
  - 败方正在撤退
  
【追击效果】
  - 追击方速度+50%
  - 追击距离最多5格
  - 撤退方无法反击
  
【追击结束】
  - 追击方到达5格或追上撤退方
  - 撤退方成功逃脱（超过5格）
```

### 4.3 围城战

```
【围城条件】
  - 攻击方军队包围城市（周围所有地块都有军队）
  - 防守方无法派出军队（被包围）
  
【围城效果】
  - 防守方：无法补充兵力，资源产出-50%
  - 攻击方：可以持续攻击城墙，无需担心侧翼
  
【破围条件】
  - 防守方有军队从外部攻破包围圈
  - 或攻击方主动解除包围
```

## 六、战斗平衡检查

### 6.1 平衡测试场景

```
【场景1：同等数量不同兵种】
  100轻甲 vs 100重甲 → 轻甲胜（克制关系）
  100飞行 vs 100轻甲 → 飞行胜（机动优势）
  100远程 vs 100重甲 → 远程胜（射程优势）

【场景2：不同数量同兵种】
  50轻甲 vs 100轻甲 → 100胜（数量优势）
  50飞行 vs 100飞行 → 100胜（数量优势）

【场景3：混合军队】
  50轻甲+50重甲 vs 100远程 → 混合胜（互补）
  30飞行+70轻甲 vs 100重甲 → 混合胜（克制+数量）
```

### 6.2 平衡修正原则

```
【修正方向】
  - 胜率 > 60%：削弱该兵种或加强被克制兵种
  - 胜率 < 40%：加强该兵种或削弱克制兵种
  - 胜率 45-55%：平衡，无需调整
  
【修正幅度】
  - 小幅修正：±5%
  - 中幅修正：±10%
  - 大幅修正：±15%（需重新测试）
```
