## 一、资源系统详细设计

### 1.1 四大公共资源

```
【食物(🌿)】
  - 获取方式：采集队采集草地/农田、自产建筑
  - 存储上限：1000 + 城市等级 × 200
  - 核心用途：维持人口、生产基础兵种
  - 被掠夺损失：50%
  
  产出公式：
    采集队产出 = 地块基础产出 × 采集效率 × 地形修正
    草地：5🌿/10秒
    农田：10🌿/10秒
    
    自产建筑产出 = 建筑等级 × 基础系数 × (1 + 科技加成)
    采集营Lv.1：5🌿/分钟
    采集营Lv.5：18🌿/分钟

【水源(💧)】
  - 获取方式：采集队采集水源地块、自产建筑
  - 存储上限：800 + 城市等级 × 150
  - 核心用途：建筑升级、工业用水
  - 被掠夺损失：50%
  
  产出公式：
    水源地块：5💧/10秒
    自产建筑：随等级递增

【矿物质(🪨)】
  - 获取方式：采集队采集岩石地块、自产建筑
  - 存储上限：600 + 城市等级 × 100
  - 核心用途：建筑升级、武器制造
  - 被掠夺损失：50%
  
  产出公式：
    岩石地块：5🪨/10秒
    自产建筑：随等级递增

【太阳能(☀️)】
  - 获取方式：阳光镜阵建筑收集
  - 存储上限：300 + 城市等级 × 50
  - 核心用途：飞行单位生产
  - 被掠夺损失：30%
  
  产出公式：
    阳光镜阵Lv.1：2☀️/分钟
    阳光镜阵Lv.5：9☀️/分钟
    天气影响：晴天+50%，雨天-50%
```

## 二、采集队系统详细设计

### 2.1 采集队配置

```
【采集队结构】
  - 最多5个单位
  - 建议全部是工蚁/采集者类兵种
  - 移动速度 = 最慢单位的速度
  - 载重限制：
    - 食物：200
    - 水源：150
    - 矿物质：100
    - 专属资源：50

【采集队数量限制】
  - 采集队数量 = 采集营等级
  - Lv.1城市：最多2支
  - Lv.5城市：最多6支
```

### 2.2 采集流程详细

```
【步骤1：选择目标】
  - 目标必须在己方控制范围内
  - 目标地块有资源产出
  - 目标地块未被敌方控制

【步骤2：移动采集队】
  - 采集队从城市移动到目标地块
  - 移动时间 = 距离 × 30秒 / 速度
  - 移动途中可能被伏击

【步骤3：开始采集】
  - 采集队到达目标地块后开始采集
  - 每10秒产出资源，存入采集队载重
  - 载满后自动返回城市

【步骤4：返回城市】
  - 采集队携带资源返回城市
  - 返回途中可能被伏击
  - 到达城市后资源进入存储

【步骤5：资源入库】
  - 资源进入城市存储
  - 超过存储上限的部分溢出（不额外产出）
```

### 2.3 伏击机制详细

```
【伏击触发条件】
  - 敌方军队移动到采集队路径上
  - 敌方军队速度 > 采集队速度
  - 距离 < 2格时触发伏击

【伏击结果】
  - 采集队与敌方军队战斗
  - 败方：
    - 采集队可能全灭
    - 资源50%被掠夺
    - 剩余资源50%损失
  - 胜方：
    - 保护资源
    - 可能追击

【预防措施】
  - 派军队护送采集队
  - 选择安全路线
  - 缩短采集时间
  - 增加采集队数量（分散风险）
```

## 三、资源存储与掠夺详细设计

### 3.1 存储上限公式

```
【存储上限计算】
  食物上限 = 1000 + 城市等级 × 200
  水源上限 = 800 + 城市等级 × 150
  矿物质上限 = 600 + 城市等级 × 100
  太阳能上限 = 300 + 城市等级 × 50
  专属资源上限 = 500（固定）

【超出上限处理】
  - 超过上限后，多余资源"溢出"
  - 采集队载满后自动返回
  - 不额外产出
```

### 3.2 掠夺机制详细

```
【城市被攻城战攻击时】
  - 存储资源有50%概率被掠夺
  - 掠夺量 = min(存储量, 攻击方军队载重)
  - 掠夺后攻击方军队需要返回己方城市才能"消耗"掠夺资源

【采集队被伏击时】
  - 采集队载重资源有50%概率被掠夺
  - 采集队死亡 = 资源全部损失（无掠夺）

【资源运输】
  - 军队可以携带资源（载重限制）
  - 从A城市运到B城市 = 运输
  - 运输途中可能被伏击
  - 资源有50%概率损失
```

## 四、经济系统详细设计

### 4.1 资源产出效率对比

```
【采集队效率】
  草地：5🌿/10秒 = 30🌿/分钟
  农田：10🌿/10秒 = 60🌿/分钟
  岩石：5🪨/10秒 = 30🪨/分钟
  水源：5💧/10秒 = 30💧/分钟
  
  采集队载重限制：
    食物：200 → 约6-7分钟满载
    水源：150 → 约5分钟满载
    矿物质：100 → 约3-4分钟满载

【自产建筑效率】
  信息素腺体：1🧬/分钟
  花田：2🌸/分钟
  蜕壳场：1🦴/分钟
  蜂王浆产房：1.5🍯/分钟
  迁徙谷物田：2🌾/分钟
  腐食场：1🦠/分钟（基于尸体）
```

### 4.2 资源消耗平衡

```
【每分钟消耗】
  人口维持：
    食物 = 人口 × 1
    水源 = 人口 × 0.5
    
  军队维持：
    食物 = 军队单位数 × 0.1
    水源 = 军队单位数 × 0.05
    
  城市维护：
    食物 = 城市等级 × 2
    水源 = 城市等级 × 1

【生产消耗】
  基础兵种：🌿30-50
  进阶兵种：🌿60-100
  重甲兵种：🌿100-150
  飞行兵种：🌿100-150 + ☀️30-50
  英雄单位：🌿300-500
```

## 五、贸易系统详细设计

### 5.1 贸易路线

```
【贸易条件】
  - 两个城市之间必须有友好关系（友好度>50）
  - 两个城市之间必须有可通行的路径
  - 贸易路线最长10格

【贸易流程】
  ① 选择贸易路线（A城市→B城市）
  ② 选择贸易商品和数量
  ③ 派遣贸易队（需要军队护送）
  ④ 贸易队移动到B城市
  ⑤ 资源交换，贸易队返回
```

### 5.2 贸易商品与价格

```
【贸易商品】
  🌿食物：1:1（所有种族）
  🪨矿物质：1:1（所有种族）
  💧水源：1:1（所有种族）
  ☀️太阳能：1:1（所有种族）
  🧬信息素：1:1.2（蚁族供给）
  🌸花粉：1:1.2（虫族供给）
  🦴甲壳素：1:1.2（甲虫族供给）
  🍯蜂王浆：1:1.2（蜂族供给）
  ⚡猎意：1:1.2（螳螂族供给）
  🌾迁徙谷物：1:1.2（蝗虫族供给）
  🦠腐质：1:1.2（蛆虫族供给）

【贸易税率】
  敌对：50%
  中立：30%
  友好：10%
  同盟：0%
```

## 六、战争经济详细设计

### 6.1 战争成本

```
【军队生产成本】
  成本 = 兵种成本 × 数量

【行军消耗】
  消耗 = 距离 × 军队数量 × 0.1资源/格

【战斗损耗】
  回收 = 战损单位成本 × 50%

【建筑修复】
  成本 = 损毁程度 × 100资源
```

### 6.2 战争收益

```
【领土收益】
  收益 = 占领格数 × 10资源/分钟

【资源掠夺】
  掠夺量 = 敌方存储量 × 30%

【人口收益】
  收益 = 敌方人口 × 10%

【科技收益】
  收益 = 敌方科技等级 × 5%
```

## 七、经济平衡设计

### 7.1 经济速度曲线

```
【前期（0-10分钟）】
  - 资源产出低，消耗少
  - 重点：快速扩张，占领资源点
  - 采集队是核心，保护采集队是关键

【中期（10-30分钟）】
  - 资源产出稳定，消耗增加
  - 重点：科技研发，兵种升级
  - 贸易系统开始发挥作用

【后期（30分钟+）】
  - 资源产出高，消耗巨大
  - 重点：军事扩张，领土争夺
  - 战争经济成为主要资源来源
```

### 7.2 经济平衡原则

```
【平衡原则】
  1. 产出与消耗平衡：确保玩家有足够资源发展
  2. 风险与收益平衡：高风险行动有高收益
  3. 采集队风险：采集队可能被伏击，增加策略深度
  4. 种族差异化：每个种族有独特的经济优势
  5. 动态平衡：事件系统使经济格局不断变化
```
