## 二、地图操作

| 操作 | 效果 |
|------|------|
| 单指滑动 | 移动视角 |
| 双指缩放 | 放大/缩小 |
| 点击地块 | 查看详情 |
| 长按地块 | 显示操作菜单 |
| 双击地块 | 快速选中 |

### 地块信息
- 己方控制：绿色边框
- 敌方控制：红色边框
- 无人控制：灰色边框
- 联盟领土：蓝色边框
- 事件区域：黄色边框

## 四、UI主题

### 颜色方案
| 元素 | 颜色 | 用途 |
|------|------|------|
| 主色调 | 🟤 棕色 (#8B4513) | 微观世界自然感 |
| 辅助色 | 🟢 绿色 (#228B22) | 生命、资源 |
| 强调色 | 🟡 金色 (#FFD700) | 重要信息、奖励 |
| 警告色 | 🔴 红色 (#DC143C) | 危险、战斗 |
| 信息色 | 🔵 蓝色 (#1E90FF) | 科技、信息 |
| 联盟色 | 🟣 紫色 (#9370DB) | 联盟相关 |

### 字体方案
| 元素 | 字体 | 大小 |
|------|------|------|
| 标题 | 粗体无衬线 | 24px |
| 正文 | 常规无衬线 | 16px |
| 说明 | 细体无衬线 | 12px |
| 数字 | 等宽字体 | 18px |

## 五、UI设计原则

1. **微观视角**：UI元素放大，增强微观世界沉浸感
2. **简洁清晰**：信息层次分明，避免信息过载
3. **主题统一**：符合昆虫世界的视觉风格
4. **交互友好**：操作直观，响应及时
5. **自适应**：适配不同屏幕尺寸
