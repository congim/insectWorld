## 一、事件系统

### 触发逻辑
```
每游戏日（现实10分钟）检查一次事件池
  ├─ 随机事件（30%）
  ├─ 季节事件（固定）
  └─ 玩家行为触发（PvP导致仇恨事件）
```

### 天气事件

| 事件 | 触发频率 | 持续时间 | 预警时间 | 影响 | 应对选项 |
|------|----------|----------|----------|------|----------|
| 🌧️ 暴雨 | 每10分钟 | 30秒 | 2分钟 | 地面单位移动-50% | A.启动排水(💧500) B.撤回单位 C.无视 |
| ☀️ 干旱 | 每20分钟 | 60秒 | 3分钟 | 水源产出-50% | A.挖掘地下水(🪨300) B.使用储备(💧200) C.无视 |
| 💨 狂风 | 每15分钟 | 20秒 | 1分钟 | 飞行单位失控 | A.加固建筑(🪨200) B.召回飞行单位 C.无视 |
| 🔥 野火 | 每赛季2-3次 | 60秒 | 5分钟 | 森林区域每秒30伤害 | A.挖掘防火带(🪨500) B.紧急撤离 C.无视 |

## 二、赛季系统

### 赛季结构
```
赛季时长：7天
每赛季重开地图，但保留「遗产」进度

第1-2天：发展期（建立城市，发展经济）
第3-4天：扩张期（扩张领土，接触玩家）
第5-6天：冲突期（结盟/宣战，领土争夺）
第7天：决战期（最终决战/生存到最后）
```

### 赛季遗产

| 遗产类型 | 保留内容 |
|----------|----------|
| 🏆 段位 | 根据赛季排名给予，永久显示 |
| 🐛 英雄等级 | 英雄经验跨赛季保留 |
| 📖 图鉴 | 解锁的种族/兵种/事件永久记录 |
| 🪙 赛季货币 | 可兑换皮肤、加速道具（非付费） |
| 🎨 皮肤 | 跨赛季保留 |

### 赛季奖励

| 排名 | 奖励 |
|------|------|
| 第1名 | 🏆传说段位+🪙5000赛季货币+🎨传说皮肤 |
| 第2-3名 | 🏆史诗段位+🪙3000赛季货币+🎨史诗皮肤 |
| 第4-10名 | 🏆稀有段位+🪙2000赛季货币 |
| 第11-50名 | 🏆普通段位+🪙1000赛季货币 |
| 第51-100名 | 🏆参与奖+🪙500赛季货币 |

## 三、胜利与失败条件

### 胜利条件
| 胜利类型 | 条件 |
|----------|------|
| 征服胜利 | 消灭所有敌对城市 |
| 领土胜利 | 控制地图60%以上地块 |
| 生存胜利 | 存活到赛季结束 |
| 科技胜利 | 研发所有科技 |

### 失败条件
| 失败类型 | 条件 |
|----------|------|
| 城市沦陷 | 城市中心被摧毁 |
| 资源枯竭 | 所有资源为0，持续10分钟 |
| 主动投降 | 玩家主动投降 |
