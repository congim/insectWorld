# InsectWorld

InsectWorld 是一个以“昆虫世界”为首个游戏包、以可复用 SLG 服务端能力为长期方向的 Go 项目。

项目不追求“任何 SLG 都只换配置即可运行”。真正的目标是：稳定机制复用、题材内容配置化、特殊玩法显式扩展，并让第一个游戏尽快形成可验证的完整闭环。

## 当前阶段

项目处于“架构收敛 + 垂直切片验证”阶段。已有代码是可复用资产，但目录存在不等于服务边界已经冻结，历史文档中的完成状态也不能代替代码和测试证据。

在完成首个可玩闭环前，默认不继续增加微服务、不为假想题材增加扩展点、不把尚未验证的能力宣传为通用能力。
